# 能力档案模板

本模板定义按 `题型-能力维度` 聚合的能力档案结构。每次评分完成后由系统轻量更新。

```yaml
题型: 归纳概括
能力维度: 要点覆盖
记录数: N
最近评分日期: YYYY-MM-DD
层级趋势: [2, 2, 3, 3]
平均层级: 2.5
最近修改建议摘要: 一句话概括最近的改进方向
掌握判定: 巩固中/已掌握
```

## 能力维度对照

### 归纳概括

- 任务符合
- 要点覆盖
- 准确有据
- 分类组织
- 简洁表达

### 综合分析

- 任务符合
- 要点覆盖
- 关系逻辑
- 结论解释
- 组织表达

### 提出对策

- 任务符合
- 问题诊断
- 针对匹配
- 可行具体
- 组织表达

### 贯彻执行

- 身份文种格式
- 内容覆盖
- 目的场景
- 结构
- 语言语气

### 申发论述

- 立意扣题
- 材料运用
- 论证深度
- 结构
- 论据例证
- 语言

## 更新规则

- 文件路径：`<状态根>/能力档案/<题型>-<能力维度>.md`
- 每次评分后读取已有文件，用 Edit 追加新层级值到 `层级趋势`
- 重新计算 `平均层级` 和 `记录数`
- 更新 `最近评分日期` 和 `最近修改建议摘要`
- 不重写整个文件
- `掌握判定`：连续 3 次层级 ≥ 3 可判定为"已掌握"
