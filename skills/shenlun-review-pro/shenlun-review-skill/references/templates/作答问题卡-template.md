# 作答问题卡模板

本模板是申论版错因卡的可读导出格式。SQLite 中的得失账本是权威源，不手工维护另一份冲突状态。

```yaml
问题卡ID: issue-<score_id>-<sequence>
作答ID: answer_id
评分ID: score_id
题型: 归纳概括/综合分析/提出对策/贯彻执行/申发论述
任务组件: 要点提取/关系分析/对策构建/文种组织/论证等
问题类型: 部分覆盖/未覆盖/材料外内容/结构缺失/表达或论证问题
主扣维度: 正式评分维度名
材料依据: 可回查原文
用户原句: 真实存在于作答的短句；完全遗漏时为空
失分理由: 可观察、可复核的原因
修改动作: 下一稿可直接执行的动作
关联方法卡: 真实调用的 sl-card ID；无则留空
二稿状态: 未比较/未改善/部分改善/已改善/退步/表面换词
记录时间: ISO-8601
```

## 成卡规则

- 完整覆盖且无结构或表达问题的要点不成卡。
- 一个问题只设一个主扣维度，避免同一缺陷重复扣分。
- 未覆盖项的用户原句必须为空，不得用“用户未写”伪装引文。
- 没有材料依据的问题不得写成得分点错因。
