# 申论学习者画像模板

画像是真实作答记录的汇总视图，不是底层事实源。

```yaml
画像版本: N
最后刷新: ISO-8601
样本范围:
  作答数: N
  题型分布: {}
  评分时间范围: start/end
当前优势:
  - 题型-能力维度: 证据摘要
优先改进:
  - 题型-能力维度: 高频问题＋下一步动作
二稿改善:
  已改善: N
  表面换词: N
  退步: N
评分校准:
  真实分数样本: N
  主要偏差: []
下一轮训练建议:
  - 一个具体、可执行的训练任务
```

## 刷新规则

- 用户明确要求，或累计3–5份新作答，或一轮训练结束时刷新。
- 每条优势和弱项都必须可回查到真实评分或作答问题卡。
- 样本不足时明确写“样本有限”，不做稳定能力结论。
- 不混入行测错因卡、行测弱点或行测学习者画像。
