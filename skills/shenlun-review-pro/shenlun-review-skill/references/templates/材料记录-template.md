# 材料记录模板

本模板用于记录用户提供的申论材料信息。评分时由系统自动填充，不需要用户手动填写。

```yaml
材料批次: <batch-id>
记录日期: YYYY-MM-DD
材料来源: photo/pdf/doc/manual
材料段落数: N
材料字数: 约 X 字
材料质量: 完整（已核对）
题型判定: 归纳概括/综合分析/提出对策/贯彻执行/申发论述（待确认）
题目要求可见: true/false
字数限制: X 字（可见/不可见）
身份要求: [可见内容]（可见/不可见）
文种要求: [可见内容]（可见/不可见）
```

## 使用说明

- 仅在材料文字通过完整性核对后创建记录；未核对 OCR 或缺失材料不持久化
- `材料质量` 由输入门禁自动判定
- `题型判定` 在材料遍完成后更新
- 此记录不直接用于评分，仅作为材料元数据
