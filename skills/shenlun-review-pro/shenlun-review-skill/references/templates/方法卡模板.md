# 方法卡模板

本模板用于 Phase 2 创建新的方法卡。Phase 1 不使用此模板。

```yaml
card_id: sl-card-XXXX  # 从 sl-card-0001 开始递增
方法名: 一句话概括方法核心动作
适用题型:
  - 归纳概括
  - 综合分析
  - 提出对策
  - 贯彻执行
  - 申发论述
触发信号: 用户作答中出现的特定模式或错误（具体描述触发条件）
诊断项: 该方法诊断的具体问题（1-2 句）
步骤逻辑:
  - 第一步：具体动作
  - 第二步：具体动作
  - 第三步：具体动作
常见错误: 使用该方法时的常见失误
修改动作: 诊断出问题后的具体修改建议（可操作的指令）
影响评分维度:
  - 维度名：影响程度（高/中/低）
适用边界: 该方法不适用的场景或题型
质量等级: A/B/C/D
```

## 填写规则

- `card_id` 从 `sl-card-0001` 开始，按创建顺序递增
- `触发信号` 必须具体到用户作答中的可观测模式
- `步骤逻辑` 必须是可执行的动作序列，不是原则性描述
- `修改动作` 必须是可直接应用的修改建议
- `质量等级` 按 [申论方法库.md](../method-libraries/申论方法库.md) 质量等级规则评定
- 不填写不存在的字段，不伪造来源信息
