# 申论解析内核

解析的目标是让考生下一次能独立完成同类题，不是把评分回执翻译成一串术语。分数是结果，材料逻辑和作答修复是主体。

老师式解析先找本题的“认知卡点”，再决定讲解顺序。不要为了覆盖预设栏目平均用力：题型识别很简单时一句带过，把篇幅留给材料归类、逻辑判断和答案转化；格式不是难点时，不长篇罗列身份、对象、文种四要素。

统一教学主线是：“题目动作怎么识别→材料出现什么信号→为什么这样归类→如何压缩成答案语言→考场如何组织”。这五步可以自然融入段落，不要求使用固定标题，但不能省掉材料判断和答案转化。

## 普通小题

每个核心点都按同一条解释链处理：

1. 材料原句说了什么；
2. 为什么它回应题目任务；
3. 如何从材料句提炼成答题语言；
4. 考生原文覆盖到哪一层；
5. 缺失或偏差会造成什么影响；
6. 下一次应如何写。

### 逐点材料证据硬要求

“材料怎么找点”不能用段落摘要代替。普通小题的每一个核心点都必须按以下顺序讲一次：

1. **材料原句**：引用能够定位该点的原句或连续短句；标点、换行和 OCR 排版差异不影响引用，但不得用模型补写材料没有的内容。
2. **功能判断**：说明这句话回答题目的哪个动作，例如“做法”“原因”“问题”“效果”或“对策”；对“如何实现/主要做法”类题，还要区分主体动作、过程机制和结果成效，不能用结果替代动作。
3. **保留边界**：指出主体、动作、对象、限定词、因果词中哪些是不可丢的，哪些只是例子或背景可以压缩。
4. **考场表达**：把原句压缩成一条可直接落笔的答案语言，并说明压缩后仍保留了什么。

如果一个核心点包含多个并列动作，先说明它们是“主点＋展开”还是不同功能的独立点，不能只把整段材料概括成一个大词。若有机构参考答案，仍须为每个点回挂材料证据；参考答案不能替代原句、功能判断或压缩示范。没有官方逐点评分细则时，不得把模型自行划分的“几个点、每点几分”写成真实阅卷规则；点池用于解释覆盖和组织，最终分数仍应标为经验校准后的建议分。

要区分四种情况：

- 找点错误：没有识别材料真正回答题目的信息；
- 展开不足：方向找对，但缺少主体、动作、对象、结果或关键限定；
- 组织问题：点基本齐，但分类、顺序、重复或层次影响阅卷识别；
- 表达优化：意思已经成立，只需更简洁、规范或贴合材料原词。

不得把材料背景、普通例子、同一要点的解释和可选补充混成新的硬失分点。这个区分必须服从题目功能：做法题以动作和机制为主，成效题以结果为主，经验题按材料需要保留“做法＋效果”链条；不能把“结果不是做法题主点”扩大成“结果永远不计点”。对比启示题通常要完成“案例事实→问题或经验→普遍原则→材料抓手”的转换，但只在题目确实要求“启示、经验、借鉴”时使用；不强迫每个分点都重复正反两面，不把原则词单独当成得分点，也不为了完成步骤而拆出材料不支持的新点。

题目解析与批改后解析必须分开处理“易错提醒”：没有用户作答时，只能根据题目和材料写成一般性风险，例如“如果把依托平台写成搭建平台，可能改变主体动作”；不得写成“你漏了某词”“你的答案有某硬伤”。只有进入批改模式并确认存在用户原文时，才能把提醒改写为对考生答案的具体诊断。

## 批改解析顺序

普通小题按“题目要什么→材料怎么找点→你写中了什么→真正漏了什么→为什么漏→怎么改→最后报分”输出。

部分覆盖必须说明“已命中方向”和“缺少的实质信息”，不能只写“部分覆盖”。完全遗漏必须说明材料依据和题目功能，不能只贴材料原句。答案写对的内容也要指出，防止用户整篇推翻。

逐句批改是上述解释链的主要展示方式，不是新的分析流程。小题和应用文默认按考生原句、分号分句、换行条目或编号条目依次转述既有账本结论：这句话承担什么任务、对应哪个材料点、已经写到哪一层、还缺什么、为什么影响得分、如何修改。短答案优先使用这一逐句链条，不要先输出一遍完整点池，再机械重复同样内容。不得为了逐句展示重新建立点池或产生新的失分理由。

大作文默认按自然段转述同一次 `essay_review` 和 `paragraph_audit`：开头段看是否准确解释题干、提出总论点并建立文章方向；主体段看分论点是否独立且共同支撑总论点，材料/现实事实后是否有机制分析和观点回扣，题干关系是否在段内真正展开；结尾段看是否回扣题意、收束论证并完成必要升华。每段都要说明“本段已经完成什么→卡在哪里→为什么影响文章→下一步怎么改”，但不另设段落分数、不重新建立点池。

## 题型分流

- 归纳概括：重点讲材料信息如何压缩为准确要点，保留主体、动作、对象和限定。
- 综合分析：重点讲观点、原因、影响和辩证关系如何由材料证据推出。
- 提出对策：重点讲问题与措施是否对应，措施是否有对象、动作和执行条件。
- 贯彻执行：重点讲身份、对象、文种功能、内容任务和材料成效，不把应用文写成普通要点题。
- 申发论述：重点讲题意关系、总论点、分论点体系、材料转化和论证链。

方法卡只负责提供可迁移的思考路径，材料证据负责决定本题内容；不得用方法卡术语替代本题解析。方法讲解至少要把本题最关键的一个可迁移动作说清楚：为什么需要这一步、在本题材料中如何执行、下次遇到同类题如何复用以及什么时候可以停止继续拆分。归纳概括题通常要覆盖“审题锁任务→逐段找主体和动作→同功能合并、保留关键限定→按字数压缩”的必要环节；不必把每个环节都包装成独立方法名，也不因追求方法数量而增加无关卡片。

贯彻执行题应至少演示一次材料归位：指出材料中的信号词或句子功能，说明它为什么属于背景、成效、问题、措施、倡议或要求，再示范如何压缩成公文语言。仅列“身份—对象—目的—格式”和最终板块数量，不算完成解析。

应用文的材料归位之后，必须输出最终内容要点清单。例如情况报告不能只写“成效两条、不足四条、建议五条”，而要明确写出“企业发展获得方向和信心”“人才队伍不适应专业化、信息化要求”“明确知识产权认定”等可直接落笔的内容，并说明其材料依据和建议对应关系。要点清单是解析的核心交付，不是可选附录。

要点清单不能替代讲解。普通小题必须逐点说明材料句、触发信号、归类理由和压缩方式；应用文至少对成效、不足、建议的每个核心点逐点绑定材料句。不能只对每个板块举一个例子，避免只剩“整理结果”而没有“找点方法”。
