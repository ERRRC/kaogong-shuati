# 申发论述协议

本文件只定义该题型的证据、覆盖和定档细节。材料核验、作答映射和参考校准在同一次入口编译中完成；本文件不定义命令调用顺序。

## 题型识别信号

- "根据给定资料，联系实际，写一篇议论文"
- "自选角度，自拟题目"
- "见解深刻/思想深刻"
- "1000-1200 字"或类似大篇幅字数要求
- 明确要求"议论文""策论文""政论文"

## 默认维度与权重

| 维度 | 权重 | 说明 |
|---|---|---|
| 立意扣题 | 20 | 中心论点是否准确扣住材料主题 |
| 材料运用 | 15 | 是否恰当引用和使用材料论据 |
| 论证深度 | 25 | 论证是否深入、有层次、有说服力 |
| 结构 | 15 | 文章结构是否完整、逻辑是否清晰 |
| 论据例证 | 10 | 论据是否充分、例证是否恰当 |
| 语言 | 15 | 语言是否流畅、表达是否准确 |

## 材料遍重点

- 提取材料的核心主题和核心观点
- 标注材料中可用于论证的事实、数据、案例
- 提取材料中的观点冲突或多层次论述
- 标注材料中隐含的政策方向或价值取向

## 作答遍重点

- 检查立意是否准确扣住材料主题（偏离材料主题是致命问题）
- 评估材料论据的使用是否恰当（是否生搬硬套、是否服务于论点）
- 评估论证深度（是否停留在表面还是层层深入）
- 检查结构完整性（标题、开头、主体、结尾）
- 评估论据是否充分支撑论点
- 检查分论点是否由题目/划线句出发主动设计成一条逻辑线，而不是机械拼接材料中的三个话题或三个对策
- 检查模板化症状：题目替换式开头结尾、空泛排比、材料只作装饰、分论点没有题目专属性
- 区分材料定位与文章表达：解析中可以用“资料X”定位证据，范文中应优先写材料主体、行动和结果；偶尔使用“资料X中”不扣分，只有反复依赖材料编号、没有完成论据转化时，才作为表达或材料运用的弱化信号

## 校准遍重点

- 参考答案的立意方向是参照，允许有合理深度差异
- 不要求论证结构与参考完全一致
- 论据可以不同，但需有效支撑论点
- 语言风格可有差异，但需准确流畅
- 有机构立意、范文或老师评语时，以其作为候选题意和论证方向，回题干核验核心命题和关系，回材料核验论据支撑；不再平行重建并复刻一套范文结构。
- 范文分论点、材料顺序和语言风格均不是唯一答案，只用于查漏、识别偏题和补充论证可能性。

## 常见失分模式

| 失分模式 | 典型表现 | 对应维度 |
|---|---|---|
| 立意偏离 | 中心论点未扣住材料主题 | 立意扣题 |
| 论证浅薄 | 停留在表面分析，缺乏深入展开 | 论证深度 |
| 材料堆砌 | 大段照搬材料，未加工整合 | 材料运用 |
| 结构松散 | 段落之间缺乏逻辑衔接 | 结构 |
| 论据不足 | 论点缺乏充分论据支撑 | 论据例证 |
| 语言空泛 | 大量口号式表达，缺乏实质内容 | 语言 |

## 修改建议方向

- 确认中心论点是否准确扣住材料主题
- 深化论证层次，避免停留在表面
- 精选材料论据，确保服务于论点
- 强化段落之间的逻辑衔接
- 补充论据支撑薄弱的论点
- 减少空泛表述，增加具体分析

## 模板使用教学（解析时必须输出）

模板可以用，但只能复用结构，不能替换现场思考。

### 可以复用

- 开头的“背景—问题/意义—中心论点”结构；
- 分论点的“观点—材料/事实—分析—回扣”论证链；
- 结尾的“总结—行动/展望—回扣主题”结构；
- 常用的因果、递进、辩证和治理链条。

### 不应直接套用

- 与题目无关的万能背景和名言警句；
- 把主题词替换进固定句式的分论点；
- 三个材料话题直接拼成三个分论点；
- 没有材料支撑的宏大口号和政策套话；
- 与正文没有关系的万能结尾。

### 解析时必须指出

- 哪些句子只是模板，为什么不能直接使用；
- 哪个分论点逻辑链条薄弱，缺少什么关系或分析；
- 哪些位置应当现场生成题目专属内容；
- 推荐背诵结构型范文：重点背“如何展开论证”，不背整篇文章。

阅卷人不是在寻找文采，而是在快速识别文章是否真正回应题目、是否有逻辑、是否有材料支撑。模板的目标是提高稳定性，不能让阅卷人一眼看出全文可以替换主题。

## 关系型大作文的材料归并与论证转化（补充操作）

这类题的核心不是背一套哲学理论，而是把题干关系转化为自己的论证线。解析和批改时按以下顺序操作：

1. **先判关系**：明确题目要求处理的双方、连接方式和方向，例如条件、因果、相互促进、对立统一或由分到合；先判断关系是核心命题还是辅助线索，再决定关系在文章中需要展开到什么程度。
2. **再画关系地图**：逐则材料记录“主体/事实—矛盾或条件—行动机制—结果”，标出它是在说明关系的一端、连接机制、正面效果还是反面边界。材料按共同回答的关系归并，不默认一则材料对应一个分论点。
3. **设计分论点**：从题干命题主动设计两个或三个处于可比较层级的分论点，可以形成并列、递进、因果、辩证或治理链；每个分论点都要回答总论点的一部分，并说明双方如何发生联系。材料只负责支撑，不负责替考生自动生成分论点。不要为了凑数量强行拆成三点，也不要强行套“量变质变”等理论。
4. **完成段落转化**：每个主体段至少形成“分论点—具体主体/行动/事实—关系分析—回扣总论点”的链条。事实之后必须补一句解释，说明它为什么体现题目关系、通过什么机制产生结果；不能只把材料换成“资料X中……”或只堆案例。
5. **最后复核**：检查每个分论点是否有独立功能、是否重复、是否同层，是否覆盖关系双方及连接语；检查跨材料使用是否服务同一论点；检查理论、名言和联系实际是否真正解释材料关系。若只剩标题和开头提到关系，主体没有展开，应标为关系名义提及；若只是个别套话，不得直接判定为模板化降档。

**使用边界**：固定开头、结尾、哲学标签、三段结构和段落字数只能作为备选工具，不能作为评分标准。只有当模板化同时造成题目针对性弱、材料转化不足或论证线断裂时，才限制高档；结构相似本身不等于套作，合理使用现成论证结构也不等于失分。

## 维度等级锚点表

以下锚点使用跨题通用的可观察行为描述，不引用任何现有 E2E 材料。

### 立意扣题（权重 20）

**判断顺序**（必须按此顺序逐条确认）：

1. 是否回应题目核心命题。
2. 是否处理题目要求的概念或关系。
3. 是否贯穿全文，而非只在标题或开头出现。
4. 是否偏题、缩题或偷换概念。

**不得**把"观点普通"直接等同于不扣题。观点准确性优先于深刻性：只要准确回应核心命题且贯穿全文，即使见解不够深刻，也不得低于 3。

| 层级 | 锚点 |
|---|---|
| 0 | 中心论点与材料主题完全无关，或严重偏题、偷换概念 |
| 1 | 中心论点涉及材料主题，但大量内容偏题、缩题或偷换概念，论点未贯穿全文 |
| 2 | 中心论点基本扣住材料主题，但存在以下问题之一：论点仅在标题/开头出现未贯穿全文、对核心概念理解有偏差、回应了次要命题而非核心命题 |
| 3 | 中心论点准确扣住材料主题，贯穿全文，对核心概念理解正确；见解可不够深刻但不偏题 |
| 4 | 中心论点精准扣住材料主题，贯穿全文，准确处理核心概念和关系，见解深刻且有独立思考 |

### 材料运用（权重 15）

区分以下层次：

| 层级 | 锚点 | 行为特征 |
|---|---|---|
| 0 | 未使用材料或严重误用 | 全文无材料论据，或材料引用与论点矛盾 |
| 1 | 简单复述材料 | 大段照搬材料原文，未加工整合，未服务于论点 |
| 2 | 材料部分支持观点 | 引用了部分材料论据，但覆盖面窄、多数停留在表面引用 |
| 3 | 材料支持观点 | 引用的材料论据能有效支撑论点，覆盖面较广，仅有少量论据运用可更充分 |
| 4 | 材料被转化为论据并完成解释 | 材料论据经加工转化为论证支撑，覆盖面广，每个论据都完成"引用—解释—支撑论点"的完整链条 |

### 论证深度（权重 25）

明确区分以下层次。**不得**以文采、篇幅或例子数量替代论证深度。

| 层级 | 锚点 | 行为特征 |
|---|---|---|
| 0 | 无论证，只有观点或口号 | 全文无任何理由或论据支撑 |
| 1 | 只有观点或口号 | 有论点但论证缺失，或论证与论点脱节 |
| 2 | 有理由但关系单薄 | 形成"观点+理由"的基本结构，但理由与论点关系单薄，缺乏材料/例证支撑或解释 |
| 3 | 形成观点—理由—材料/例证—解释 | 每个分论点有完整论证链，理由充分、有材料支撑、有解释说明 |
| 4 | 能处理因果、条件、边界、反面或关系层次 | 在完整论证链基础上，能分析因果机制、边界条件、反面情况或多层次关系，论证深入有层次 |

**注意**：有完整论证链但文采普通，论证深度不得因语言问题降档。语言问题计入 `语言` 维度。

### 结构（权重 15）

| 层级 | 锚点 |
|---|---|
| 0 | 无结构或结构完全混乱 |
| 1 | 有初步结构但层次严重混乱，段落之间无逻辑衔接 |
| 2 | 结构基本完整（标题+开头+主体+结尾），但段落衔接不够流畅或篇幅失衡 |
| 3 | 结构完整清晰，段落逻辑衔接基本流畅，仅有少量篇幅或衔接可优化 |
| 4 | 结构严谨，逻辑递进清晰，篇幅均衡，开头有力、结尾收束充分 |

### 论据例证（权重 10）

| 层级 | 锚点 |
|---|---|
| 0 | 无论据或论据与论点矛盾 |
| 1 | 论据单薄，仅有一两个且运用不充分 |
| 2 | 有一定论据，但覆盖面窄或部分论据与论点关联不强 |
| 3 | 论据充分，能有效支撑各分论点，仅有少量论据可更恰当 |
| 4 | 论据丰富恰当，材料内论据与合理补充论据结合，每个分论点都有充分支撑 |

### 语言（权重 15）

| 层级 | 锚点 |
|---|---|
| 0 | 语言不可读或严重语病 |
| 1 | 大量语病，语言与文体不符 |
| 2 | 语言基本流畅，但存在套话、表述空泛或部分表达不当 |
| 3 | 语言流畅准确，符合文体要求，仅有少量表达可优化 |
| 4 | 语言精准生动，表达有力，无套话，修辞恰当 |

## 评分与分档

申发论述固定使用 `by_dimensions`（维度/整体）评分，不走小题逐点计分。

定档顺序：

1. 立意是否扣题、是否覆盖并正确处理题目核心关系；
2. 分论点是否由题目和划线句设计出一条逻辑线；
3. 材料是否完成“事实/案例—分析—支撑观点”的论证链；
4. 论证深度、结构、论据和语言是否达到对应档位；
5. 检查模板化风险。只有模板泛化同时伴随题目针对性弱、材料支撑弱或论证线断裂，才限制高档；单句套话不自动降档。

`essay_review` 必须记录：中心论点、分论点链条、分论点关系、材料支撑、推理桥梁、反面/边界、回扣总论点，以及题目针对性、论证线状态、材料支撑状态和模板风险。

关键标签不得只写结论。`judgment_evidence` 必须保存题干关系原句、中心论点原句、关系双方原句、关系连接语、缩题/偏题理由、逐个分论点审核和材料转化原句。引擎必须验证作文引文可在用户答案中找到，分论点审核数量与分论点链一致，并检查“关系完整/遗漏”“分论点体系正常/材料并列”等标签与证据是否自洽。证据不足时停止正式评分，不得用模型印象补齐。

### 核心命题与关系门禁

关系型题目先检查题干要求处理的概念双方及其连接方式，不能把“分与合”“快与慢”“守正与创新”等关系命题缩成单边口号。

先判断关系地位：`core` 表示题干核心任务就是解释或处理该关系；`supporting` 表示关系只是辅助理解材料或支撑主题；`not_applicable` 表示题目不是关系命题。同样的遗漏只有在关系为核心任务时才构成严重立意缺陷。

- `relationship_coverage_status=complete`：双方及其关系均得到准确论述。
- `partial`：双方均有涉及，但关系解释不充分。
- `mentioned_only`：关系词只在标题、开头或引用中出现，主体分论点没有实质展开关系双方及其连接。
- `missing`：遗漏关系一端。
- `distorted`：把辩证、条件或目的关系曲解为简单排斥、替代或单边优先。
- `not_applicable`：题干不是关系型命题时使用。

正式定档规则：完全偏题进入四类文；核心关系仅名义提及、遗漏一端、曲解关系或论证线断裂，最高进入三类文；辅助关系缺失、立意缩窄、关系展开不足、分论点层级混乱、三则材料机械对应或材料未完成论据转化，最高进入二类文；只有核心命题、分论点体系和材料转化均成立，才允许进入一类文。标题、开头结尾模板痕迹和一般语言问题只影响档内位置，不得替代立意门禁。

每个分论点审核还必须标记是否展开关系第一方、第二方以及二者连接。关系完整至少需要主体中出现双方的实质展开和关系解释；只在标题或开头出现关键词，不能据此判为 `partial` 或 `complete`。

一致性门禁：核心关系为 `mentioned_only/missing/distorted` 时“立意扣题”不得高于2级；只有分论点体系为 `broken` 时才限制“结构”最高2级；只有论证线为 `broken` 时才限制“论证深度”最高2级。`material_parallel`、`mixed_levels` 和 `weak` 进入整体定档，但不与单个维度机械绑定。原型解析没有真实命中回执时停止正式评分，不得选择“最近原型”继续。

40 分作文经验档位上限：一类文 32 分，二类文 27 分，三类文 19 分，四类文 13 分。该上限用于无官方细则时的分布校准，不冒充官方固定评分标准；正式分数取整数。

材料用于印证和支撑考生设计的论点，不要求分论点机械按材料顺序排列；但文章必须保持论证自洽，不能把材料话题简单拼成分论点。分论点还必须处于可比较的逻辑层级，并共同支撑总论点。

## 题目解析输出（无考生作答）

大作文解析不能只给立意、提纲和范文，必须先把“为什么这样立意、材料怎样变成论据、段落怎样完成论证”讲清，再给示范文章。固定顺序如下：

1. **逐词拆题**：分别解释题干核心概念、限制词、关系连接词和写作任务，说明总论点必须覆盖什么，不能只复述题干。
2. **判断关系**：明确关系双方、关系类型和方向（如手段—目的、条件—结果、相互促进或辩证转化），说明文章需要如何展开双方及其连接，不能只在标题或开头点名。
3. **材料转化**：逐则材料用“事实→机制→观点”讲清楚：材料写了什么事实，通过什么行动或条件产生什么结果，最终支撑总论点或哪个分论点；说明哪些材料合并、哪些只作边界或联系实际。
4. **论证路径**：逐个分论点说明“观点→论据→分析→回扣”。必须解释事实为什么能证明该观点、分析桥梁是什么、如何回到题目关系；不能只列案例或把材料段落直接当分论点。
5. **方法联动与成稿**：说明实际使用的方法如何执行上述步骤，最后再给文章结构、易错提醒和完整范文，并复核全部材料、联系实际及字数要求。

## 批改后解析输出

大作文批改在进入总评和分论点复盘前，必须先完成题干拆解：指出题目要求写什么、核心关键词及其关系、材料范围和字数/文体限制，并将其转化为文章责任清单。至少回答“总论点要覆盖什么、分论点如何共同支撑、材料要从事实转成什么观点、联系实际怎样服务论证”。若没有完成这一步，不得直接用“立意偏”“论证弱”作为开场诊断。

题干拆解必须与真实方法卡联动：在进入文章诊断前，说明本题实际使用的方法名称、适用原因和可执行步骤。关系型命题至少说明“解释关键词→判断关系→形成覆盖双方的总论点→检查分论点是否回扣关系”；分论点设计至少说明如何拆分、推进或补充论据。方法说明只服务本题，不展示卡号或调用回执。

大作文批改的主要产品是诊断卡，不是分数回执。用户可见解析必须按以下顺序：

1. 题目真正要求：用一句话说明中心命题、关系和论证任务。
2. 总评：判断文章抓住了什么、偏离了什么。
3. 主失分点：优先说明立意/关系、总论点和分论点体系问题；每项都写“错在哪里—为什么影响阅卷—如何修复”。
4. 分论点复盘：逐段说明该段观点、与总论点关系、材料是否完成“事实—分析—观点”转化，以及缺少的关系或逻辑。
5. 次要问题：再说明标题、模板句、语言、结构和论据等档内问题。
6. 保留优点：明确哪些内容已经成立，避免用户无效重写。
7. 修改顺序：给出先改立意、再改论点体系、再改材料分析、最后改表达的可执行顺序。
8. 最后报告档位、整数分、区间和置信度，并解释分数如何由主问题决定。

不得把“立意2级、论证3级、总分19”等工程字段直接当作解析；必须翻译为用户能据此二次写作的诊断语言。
