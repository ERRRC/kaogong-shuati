# 归纳概括协议

本文件只定义该题型的证据、覆盖和定档细节。材料核验、作答映射和参考校准在同一次入口编译中完成；本文件不定义命令调用顺序。

## 题型识别信号

- "请归纳/概括/总结/提炼……"
- "用不超过 X 字概括"
- "主要内容/主要问题/主要原因"
- "请用简洁语言概括"
- 作答要求中出现"全面、准确、有条理"

补充区分：题干问“某人/某地如何解决、采取了哪些办法、怎样实现”，通常是从材料中概括既有做法或经验；题干要求“提出、制定、建议、设计对策”才是提出对策。不能仅因题目同时出现“问题”和“解决”就把概括做法改判为提出对策。

## 默认维度与权重

| 维度 | 权重 | 说明 |
|---|---|---|
| 任务符合 | 15 | 是否准确把握题目要求的概括对象和范围 |
| 要点覆盖 | 45 | 是否全面覆盖材料中的核心信息点 |
| 准确有据 | 20 | 要点表述是否准确、有材料依据 |
| 分类组织 | 10 | 要点是否分类合理、逻辑清晰 |
| 简洁表达 | 10 | 语言是否精炼、无冗余 |

## 材料遍重点

- 提取所有可采信息点，按段落标注来源
- 区分核心要点（必须覆盖）和次要信息（可选覆盖）
- 标注材料中的限定词（时间、范围、主体）

## 特征/属性概括的主次边界

当题目问“蕴含的智慧、特点、启示、经验属性”等，而不是直接问“采取了哪些做法”时，先把材料信息分为核心属性、支撑机制、具体例证和背景结果：

- 核心属性必须直接回答题目对象，并由材料的总括句、机制句或多处事实共同支撑；动作、例子和结果只有在题目明确要求时才升级为独立要点，否则并入主点展开。
- 先按功能判断候选点：回答同一问题功能的总括词、机制和具体动作应合并；回答不同问题功能、不能相互替代的内容才拆分。不要按材料段落、关键词数量或例子数量机械计点。
- 传承、文旅、品牌、技术、制度等内容不预设主次，是否为核心取决于题干对象、材料总括句和该内容能否独立回答题目；没有直接回应题干时，只作为支撑证据或可选补充。
- 建点清单、答案清单和讲解中的核心点数量必须一致；若先列候选再合并，必须明确哪些被合并、哪些降为展开或可选补充。

## 作答遍重点

- 逐要点判定覆盖状态
- 检查是否有多余信息（超出材料范围的内容标注但不评分）
- 评估分类是否合理（同类合并、异类分组）
- 并列可得分做法必须拆分为独立原子要点；总括不能自动覆盖并列子项
- 先判断点的功能是否相同：同一做法的场景、动作、例子、效果和背景合并为一个主点的展开；只有分别回应题干、不能互相替代的做法才拆为独立点。不要把“材料段落数”直接等同于“得分点数”。
- 复核材料原有顺序和逻辑；轻微换序不自动扣分，打乱因果/递进或造成独立点不可识别时才影响整体档位
- 复核同义重复和层次合并，避免同一用户表述重复计入多个点
- 覆盖表完成后必须逐行重算各状态数量，确保与表格行数一致

## 校准遍重点

- 参考答案是重要候选，不是自动生效的核心点清单；每一项都必须回到题干功能和材料核验，正常情况下保留其中有据的有效要点。
- 参考答案的分条数量不是机械点数；先与材料做同功能合并和主点/展开区分，再判断考生是否遗漏。参考答案中的支撑动作、例子或可并入其他主点的子项，不得仅因单列就自动判为独立核心；若题干和材料证明其能独立回答作答对象，保留为核心，否则合并、弱化或标为可选补充。
- 等义但不同措辞的要点不扣分
- 参考答案中多出的要点，只有在能够独立回答题目且不能被其他核心点替代时，才视为用户遗漏；否则应合并、弱化或标为可补充。
- 若参考答案存在遗漏、拔高、错列或材料冲突，批改正文须用简短冲突提示说明“参考答案—材料依据—AI选择及理由”，不得静默改写参考口径，也不得把冲突复杂化为来源分级。
- 粒度冲突按四问处理：该点是否直接回答题干、能否独立成点、能否被其他点替代、参考答案遗漏的材料内容能否独立成点。完成判断后只给一个AI采用口径，不给两套分数或让用户决定。

## 常见失分模式

| 失分模式 | 典型表现 | 对应维度 |
|---|---|---|
| 要点遗漏 | 漏提材料中明确出现的核心信息 | 要点覆盖 |
| 要点偏差 | 提取了非核心信息或误解材料 | 任务符合/准确有据 |
| 分类混乱 | 相关要点分散、不相关要点合并 | 分类组织 |
| 表述冗余 | 同一要点反复出现或过度展开 | 简洁表达 |
| 超出材料 | 加入材料中没有的信息或主观发挥 | 准确有据 |

## 修改建议方向

- 对照要点覆盖表，逐条补充遗漏要点
- 合并重复表述，精简语言
- 调整分类逻辑，确保同类归并
- 删除超出材料的内容

## 维度等级锚点表

以下锚点使用跨题通用的可观察行为描述，不引用任何现有 E2E 材料。

### 任务符合（权重 15）

| 层级 | 锚点 |
|---|---|
| 0 | 未回应概括对象，或方向与题目要求相反 |
| 1 | 涉及概括对象，但大量内容偏离题目要求的范围或主体 |
| 2 | 基本围绕概括对象，但部分内容偏离范围、混淆主体或遗漏关键限定 |
| 3 | 准确把握概括对象和范围，仅有少量边界内容偏移 |
| 4 | 精准把握概括对象、范围和限定条件，全部内容紧扣题目 |

### 要点覆盖（权重 45）

基于覆盖表比例和核心要点状态综合判断，但不只按数量机械评分。

| 层级 | 锚点 |
|---|---|
| 0 | 几乎未覆盖任何核心要点（核心要点覆盖率≈0） |
| 1 | 覆盖少量核心要点，大面积遗漏关键信息 |
| 2 | 覆盖部分核心要点，存在明显遗漏（如遗漏整类做法或关键维度） |
| 3 | 覆盖大部分核心要点，仅有少量次要要点遗漏 |
| 4 | 全面覆盖所有核心要点，次要要点基本覆盖 |

### 准确有据（权重 20）

| 层级 | 锚点 |
|---|---|
| 0 | 要点表述与材料矛盾，或大量虚构材料外信息 |
| 1 | 少量要点有材料依据，多数表述偏离材料原意或无据 |
| 2 | 核心要点基本有据，但部分表述存在偏差或过度引申 |
| 3 | 要点表述准确，有材料依据，仅有少量表述可更精确 |
| 4 | 全部要点准确还原材料原意，无偏差、无虚构 |

### 分类组织（权重 10）

**前提**：无分类需求时不得因未分类扣分。题目未要求分类（如"概括主要内容"无"有条理"要求）时，按顺序罗列即可，分类组织维度默认不低于 3。

| 层级 | 锚点 |
|---|---|
| 0 | 无任何组织痕迹，要点散乱堆砌 |
| 1 | 有初步分类尝试，但分类边界混乱、交叉严重或大量重复 |
| 2 | 有基本分类，但存在以下问题之一：分类不服务任务、同层并列不当、交叉/遗漏/重复明显、总括词与子项不匹配 |
| 3 | 分类合理，同类归并、异类分组清晰，仅有少量边界模糊或总括不够精炼 |
| 4 | 分类精准服务任务，同层并列恰当、边界清晰、无交叉重复，总括词与子项完全匹配 |

### 简洁表达（权重 10）

| 层级 | 锚点 |
|---|---|
| 0 | 语言完全不可读或严重超限 |
| 1 | 大量冗余表述，同一要点反复展开，或严重超字数 |
| 2 | 基本简洁，但存在部分冗余、重复或轻度超限 |
| 3 | 语言精炼，无明显冗余，字数合规 |
| 4 | 语言高度精炼，无一字多余，字数充分利用 |

## 逐点计分模式（v0.4）

分数由同一点池上的逐点覆盖、展开度和整体档位共同校准。内部点值是可复算的相对权重，不是官方单点扣分表。

归纳概括题使用 **keyword（按点/关键词）** 赋分模式。

### 点值分配规则

1. 只有直接回应题干、材料证据独立、与已有点不重复且可独立判断覆盖的内容，才是 scorable_point。
2. 同一主张的动作、例子、结果和背景默认作为主点展开，不另造硬点。
3. 内部点值仅表达核心与支撑内容的相对重要性；无官方细则时不对用户声称“核心点固定2分”或“解释固定1分”。

### 变化类题目的专门口径

题干出现“发生了哪些变化”“从……到……”或要求结合发展阶段概括变化时，先把每个阶段的前后转向建立为核心点。阶段中的登记、评级、系统、联合部门等具体动作，除非直接决定前后转向是否成立，否则作为展开证据或准确性校准，不得机械升级为独立硬点。

考生只要写出前后变化方向，并写出至少一个材料支持的后续动作，优先按“核心覆盖、展开不足”处理；缺少一项细节不直接把整个阶段压成低比例部分覆盖。若出现材料外词，单独标记准确性问题，不能吞掉同一条中已经写对的变化主线。

### 前置概括词的评分边界

“执法更规范”“从粗放到柔性”等句首概括词是结构提示，不是独立得分点。缺少概括词不扣分；概括词略宽泛或不够精确时，只要后文的材料动作、对象和限定已经写出，不得因此降低后文的要点覆盖。只有概括词与后文实质相反、导致主体/动作/因果关系误判，才影响对应的组织或准确性判断。批改时先评价后文实质内容，再提示概括词是否有助于阅卷识别，不能把同一问题重复计入内容分和组织分。

### 关键词匹配规则

- 用户答案中出现材料关键词或同近义词 → 满分（证据 1-2：同近义词等价）
- 用户答案用自己的话表达同一意思 → 满分（归纳概括中等义不降分）
- 有涉及但不完整（缺关键限定） → 部分覆盖
- 完全未提及 → 0 分

### 展开度

归纳概括题也必须判定展开度（v0.4 更新）：

- 当一个得分点只有“总括词”而没有任何具体解释（如只写“生存压力”）时，属于简略提及，展开不足；写出总括词和材料具体解释（如“生存压力大，收入低、就业难”）才属于充分展开。
- 本规则针对“答案只写总括词”的情形，不适用于“前置概括词＋后文已经写出实质动作”的情形。后者应按后文实际覆盖判断，不能因前置概括词不够精准而重复扣分。
- 展开度只用于区分“只有总括词”和“已写出实质动作/限定”，不得重复扣减已经完整覆盖的核心意思。
