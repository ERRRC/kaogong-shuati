# 申论复盘一体版

面向公考申论学习的解析与批改技能。把题目、材料和作答直接发给智能体，它会按申论作答逻辑帮你拆题、找点、批改和修改。

## 主要功能

- **题目解析**：拆解题干要求，回材料提取要点，讲清作答方法和组织思路。
- **作答批改**：逐条指出命中点、遗漏点和表达问题，给出修改方向与建议分。
- **五类题型**：归纳概括、综合分析、提出对策、贯彻执行、申发论述。
- **有无参考答案都能用**：有参考答案时结合材料校准；没有参考答案时依据材料独立分析。
- **整套试卷处理**：先发送整套卷子，再按题号逐题解析或批改。

## 怎么用

### 1. 解析一道题

发送：**题干 + 对应材料**。

示例：

> 用申论技能解析这道题。题干：…… 材料：……

有参考答案时可一起发送；没有参考答案也可以，技能会根据材料提取要点并给出示范答案。

### 2. 批改自己的作答

发送：**题干 + 对应材料 + 我的作答**。

示例：

> 用申论技能批改我的作答。题干：…… 材料：…… 我的作答：……

批改会说明你答到了什么、漏了什么、为什么失分，以及下一稿怎么改。

### 3. 处理整套试卷

先发送整套试卷，再指定题号。

示例：

> 这是整套申论试卷，先解析第 1 题。

或：

> 批改第 2 题，我的作答是：……

## 小提示

- 材料、题干和作答越完整，分析越准确。
- 图片或 PDF 也可以发送；文字模糊处建议补充清晰原文。
- 建议分用于定位问题、比较进步，不等同于官方阅卷分数。
