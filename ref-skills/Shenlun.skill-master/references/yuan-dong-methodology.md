# 袁东（大作文）方法论

## 核心思想

袁东的申论大作文体系的独特之处在于：**不是先想"怎么写"，而是先判断"是什么类型"**。从题干判断主题类型 → 按类型确定分论点框架 → 再从题干和材料中填充关键词。分论点的框架是类型决定的，内容是从材料中提取的。

---

## 一、审题：三种主题类型

拿到大作文题目后，第一步不是想怎么写，而是判断题干属于哪种类型。

### 1.1 单主题

**识别**：题干只围绕一个核心概念展开。

例："以'创新驱动发展'为主题写一篇文章" → 只有"创新驱动发展"一个核心

**分论点方向**：围绕单一主题的多个维度展开——为什么重要、怎么做、从哪些方面做。

### 1.2 双主题

**识别**：题干出现两个（AB型）或三个（ABC型，但前两个服务于第三个）概念。

#### AB型

特征：A 和 B 是两个并列/对立/互补的概念。

例："守正与创新""变与不变""有为与不为""效率与公平"

**分论点框架**：
| 分论点 | 方向 |
|--------|------|
| 分论点一 | A 对 B 的影响/作用 |
| 分论点二 | B 对 A 的影响/作用 |
| 分论点三 | A 和 B 双向奔赴、互相作用能产生什么 |

举例（"守正与创新"）：
- 分论点一：守正是创新的前提——只有守好根本，创新才不会跑偏
- 分论点二：创新是守正的保障——没有创新，守正会僵化失去生命力
- 分论点三：守正与创新相辅相成，在双向奔赴中推动事业行稳致远

#### ABC型

特征：题干出现三个概念，但 A 和 B 共同服务于 C。

例："以法治和德治推动社会治理现代化" → A=法治，B=德治，C=社会治理现代化

**分论点框架**：
| 分论点 | 方向 |
|--------|------|
| 分论点一 | A 对 C 的作用 |
| 分论点二 | B 对 C 的作用 |
| 分论点三 | A + B 协同对 C 的作用 |

举例：
- 分论点一：法治为社会治理现代化提供刚性约束和制度保障
- 分论点二：德治为社会治理现代化提供柔性引导和价值支撑
- 分论点三：法治与德治刚柔并济、协同发力，共同推进社会治理现代化

### 1.3 多主题

**识别**：题干出现三个及以上并列概念，需要"打组合拳"。

例："推动高质量发展需要处理好改革、发展与稳定的关系"

**分论点框架**：各主题各自的作用作为分论点，强调"组合拳"式的整体效应。

举例（"改革、发展、稳定"）：
- 分论点一：改革是动力——以深化改革破解发展难题
- 分论点二：发展是目的——以高质量发展筑牢民生根基
- 分论点三：稳定是前提——以社会稳定为改革发展保驾护航

## 二、分论点寻找法：三步走

袁东找分论点有固定的搜索顺序：

### Step 1：从题干中找关键词

先圈题干中的核心概念（如"守正""创新""法治""德治"等），题干本身往往已经暗示了分论点方向。

### Step 2：从给定材料中找

把给定材料中与题干核心概念相关的段落全找出来，标注其中的观点句、做法、成效，这些都是分论点的依据。

### Step 3：从前面小题的材料中找

如果给定材料中的信息不够支撑三个完整的分论点，**往前面的题目材料中找**。申论整套试卷的材料是有内在联系的，前面小题的材料往往能为大作文提供额外的论据和案例。

**核心动作**：始终是**寻找关键词**，不是自己编。分论点中的核心术语必须来自题目或材料。

## 三、五段三分结构

### 3.1 整体布局

```
标题（1行）— 对仗式，直接关联题干核心词
首段（150-200字）— 破题 + 亮明中心论点
分论点一（250-300字）— 政策理论 + 案例分析
分论点二（250-300字）— 政策理论 + 案例分析
分论点三（250-300字）— 政策理论 + 案例分析
尾段（100-150字）— 回扣 + 升华
```

### 3.2 标题写法

- **观点式**：直接亮明中心论点。"以高质量发展推动中国式现代化"
- **对仗式**：两个短语构成。"守正为基 创新为翼"
- **比喻式**：用比喻增强画面感。"让制度长出牙齿 让权力在阳光下运行"

标题必须直接关联题干核心词。阅卷人看标题 2 秒钟判断是否偏题。

### 3.3 首段写法

**三层递进**：
1. **引出话题**（1-2句）：从时代背景或材料现象切入
2. **点明问题/意义**（1-2句）：这个话题为什么值得讨论
3. **亮明中心论点**（1句）：最后一句话必须是中心论点，不能含糊

### 3.4 分论点段内结构

1. **分论点句**（1句，段首）：直接说出这个分论点
2. **政策理论支撑**（2-3句）：转述政策精神，点明与话题关联
3. **案例分析**（3-4句）：具体案例，有名有姓有细节
4. **小结论**（1-2句）：回扣本段分论点

三个分论点字数基本对等，不能一长一短。

### 3.5 尾段写法

1. **回扣**：用新话术重申中心论点（不照抄首段）
2. **升华**：上升到国家发展、人民幸福的层面

不要做：提新分论点、用"但是"转折、用"我希望/我相信"等主观表达。

## 四、双线论述法

每个分论点段内部采用"政策理论线 + 案例分析线"双线并行。

### 政策理论线
- 来源：二十大报告、政府工作报告、领导人讲话等
- 写法：用自己的话转述政策精神，说明与当前话题的关系
- 不整段引用，点到为止

### 案例分析线
- 来源：给定材料案例、前面小题材料中的案例、社会热点案例
- 写法：简述案例 + 提炼启示，不堆砌细节

### 双线融合示例

> **分论点：推动基层治理现代化，需要发挥数字技术的赋能作用。**
>
> 党的二十大报告明确提出"加快建设数字中国"，基层治理的数字化转型正是数字中国建设的重要一环。**(政策理论线)**
>
> 浙江"浙里办"App 整合了 2000 多项便民服务事项，让群众办事从"最多跑一次"变为"一次不用跑"。**(案例分析线)**
>
> 数字赋能不是简单的"技术叠加"，而是推动治理流程再造和服务理念升级。

## 五、模板与创新：模板是底线，不是天花板

### 5.1 模板的定位

袁东的 AB/ABC/多主题框架是**保底工具**——确保你在考场上不跑题、有话说、结构稳。但它不是唯一正确的写法。

批改时的判断原则：
- **如果用户按模板写了** → 检查框架是否正确、分论点是否到位，得分稳在二类文以上
- **如果用户没按模板，但结构自洽、论证有力** → **不扣分**，反而要加分鼓励创新

### 5.2 超越模板的正确姿势

以下情况即使不套模板也应获得高分甚至加分：

**1. 独到的切入角度**
例："守正与创新"不只是"A对B/B对A/双向奔赴"，用户从"守正的本质是对时间的敬畏，创新的本质是对变化的拥抱"这种哲学层面切入 → 格局更高，加分。

**2. 新颖的论证结构**
例：不用"三个并列分论点"，而是用一个核心故事贯穿全文，层层剥开 → 只要逻辑自洽、论证充分，不扣结构分。

**3. 深刻的独立分析**
例：用户对材料中的某种现象提出了材料之外但合理的深层原因分析 → 不是"脱离材料"，而是"在材料基础上独立思考"，加分。

**4. 有辨识度的语言风格**
例：不用标准"政策腔"，而是用有文采但不浮夸的语言写出独特的论述节奏 → 在一堆模板作文中一眼跳出来，加分。

### 5.3 评判时的具体操作

| 情况 | 处理 |
|------|------|
| 按模板写，结构正确 | 基础分稳，看论证深度和语言表达 |
| 按模板写，但分论点套路化、空洞 | 指出模板架对了但内容没填好 |
| 没按模板，但结构自洽、有新意 | **不扣结构分**，在"论证充分性"和"语言表达"维度可额外加分 |
| 没按模板，结构混乱 | 建议先用模板稳住框架，再尝试创新 |
| 模板框架对，但某一段有惊艳的独立发挥 | 点赞该段，鼓励更多类似发挥 |

### 5.4 核心理念

> **模板教会你怎么走，但不规定你必须走哪条路。**
> 批改的目的不是把所有人塑造成同一个答题机器，而是帮每个人找到自己的最佳表达方式——模板是拐杖，等你走稳了，拐杖就可以扔了。

### 5.1 三个必看来源
1. **历年真题主题演变** — 看趋势
2. **当年政府工作报告** — 看工作重点
3. **领导人年内讲话** — 看高频关键词

### 5.2 命题预判口诀
> "看三年，定方向；看当年，定重点；看层级，定角度"

- 国考副省级：偏宏观政策、理论深度
- 国考地市级：偏基层治理、实操导向
- 国考行政执法：偏法治建设、执法规范化
- 省考：偏本省特色工作、区域发展

## 六、袁东体系的"气质"

1. **先判断类型，再找分论点** — 类型决定框架，材料填充内容
2. **分论点必须来自题干或材料** — 关键词是找出来的，不是编出来的
3. **AB型写双方的互相作用，ABC型写两者对第三者的作用** — 框架不能搞混
4. **结构规范化** — 五段三分是底线
5. **语言简洁有力** — 不堆砌辞藻，靠逻辑和内容取胜
