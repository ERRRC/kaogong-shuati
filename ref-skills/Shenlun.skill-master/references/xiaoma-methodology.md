# 小马哥（B站）方法论

## 核心思想

小马哥的申论方法极度务实，核心就一句话：**"答案都在材料里，别自己瞎编。"**

他的教学风格直白、实操，适合基础薄弱和追求稳定得分的考生。

---

## 解题总框架

### 四项基本原则

1. **问啥答啥，有啥写啥** — 题目问什么就答什么，材料有什么就写什么。不要脑补材料，不要自我发挥。
2. **理解语义，技巧辅助** — 理解原文语义是最重要的，技巧只是辅助。读懂材料比套模板更重要。
3. **读出层次，找对大哥** — 材料有层次结构，区分"大哥"（主旨句）和"小弟"（支撑细节）。找对大哥，不丢核心要点。
4. **书写规范，形意结合** — 回归原文进行适当归纳，排版有条理。不过度口语化，但也不要过度修饰。

### 材料定位法

1. **先看问题，再看材料** — 带着问题读材料，不漫无目的
2. **圈关键词** — 读到和问题相关的词直接圈出来
3. **抄就完了** — 把圈出来的关键句按逻辑排好，就是答案

### 答案结构铁律：总括句 + 分类归并

小马哥写在答题纸上的答案有固定结构，不管什么题型：

**第一句必须是总括句**——一句话给阅卷人"全貌"。格式："XX与XX签署/推进/建立了XX，XX格局初步形成。"

**然后 3-5 条分类归并**——不是按材料出现顺序罗列，而是按"领域"重新归类。每条 = **上位概括词 + 具体内容（举措→成效）**。

**分类逻辑**（由硬到软）：
- 交通/基建 → 人才/人力 → 产业/经济 → 民生/服务
- 制度 → 执行 → 保障
- 政府 → 社会 → 个人

**示例**（2025河南省考真题）：

材料散点：水源共享、城际公交、高速免费、人才协议、干部挂职、文旅共建、新能源项目、企业生态圈、零工就业、物流共建……共10个散点。

小马哥的归并：
```
[总括] A区与B县签署战略合作协议，推进了80余项合作，"1+1>2"格局初步形成。

一、促进交通互联。→ [归入：城际公交+高速免费+物流]
二、推动人才交流。→ [归入：人才协议+干部挂职+文旅共建]
三、共建产业生态。→ [归入：新能源项目+企业生态圈]
四、促进民生融合。→ [归入：水源共享+零工就业+就业平台]
```

**归纳口诀**：跟路有关的归交通，跟人有关的归人才，跟钱和企业有关的归产业，跟群众生活有关的归民生。10个散点装进4个筐。

### 小马哥的材料批注法

不像白鹭那样分类标记，小马哥的做法更简单：
- 直接用横线划出跟题目相关的句子
- 在旁边标注这句话对应"第几个要点"
- 最后把划线的句子按逻辑顺序排列输出

## 各题型方法论

### 一、归纳概括题

**四项原则**：
1. **问啥答啥，有啥写啥** — 不要脑补材料，题目问什么就答什么
2. **观察材料的行文顺序** — 材料自身的结构就是答案的逻辑
3. **读出层次，找对大哥** — 区分主旨句（大哥）和支撑细节（小弟），大哥必留，小弟酌情
4. **适当归纳，不要过度** — 可以合并同类项，但不能把材料关键词归没了

**笔记要点**：
- 注意题目给定的范围内容和具体要求，提取文章关键信息
- 不要过于口语化的表达，可以适当归纳
- **材料原文是重心！** 一切以材料内容为主，不要自己脑补或修改原文
- 写作有层次，注意区分"大哥"和"小弟"
- 学会观察材料的行文顺序，进行归纳总结

### 二、对策启示题（做法/对策）

**三种对策来源**：
1. **概括对策** — 材料中直接有的做法，照抄
2. **借鉴对策** — 材料中案例/经验的做法，转化成自己的对策
3. **提出对策** — 材料中有问题但没对策，把问题反过来就是对策

**解题步骤**：
1. 看题目问什么，锁定材料范围
2. 先在材料中找**现成的对策**（某人说了什么做法、某地做了什么、文件规定了什么）→ 直接抄
3. 再找**可借鉴的经验**（其他地方的成功做法）→ 转化表述
4. 最后找**问题**（困难/不足/弊端）→ 反过来就是对策
5. 整理输出，宁多勿少

**小马哥特别强调**：
- "材料里有的对策你千万别自己重新说，改人家的话反而把关键词改没了"
- 对策题不怕写得平实，怕的是漏点
- 如果一条对策很长，可以拆成两条写，增加得分机会
- **把问题反过来说，把名词变动词**

### 二、综合分析题

**核心认知**：综合分析题的"分析"其实是"梳理材料中别人的分析"，不是让你自己分析。

**模板 → 只是参考，不是每道题都套！**

基本框架：是什么 → 为什么 → 怎么办

但 **必须看材料内容决定**：
- 材料偏正面（说好处多）→ 好的一面 → 意义 → 对策
- 材料偏负面（说问题多）→ 不好的一面 → 影响 → 对策
- 材料有正有反 → 正反都写 → 对策

材料有什么角度就写什么角度，没有的角度不要硬编。

**解题步骤**：
1. 回到材料中这个词/这句话的上下文，读懂原意
2. 判断材料偏向（正面/负面/辩证）
3. 按材料偏向选择展开角度，把材料中相关句子串起来
4. 结尾：材料有对策就抄对策，无对策就一句话收尾即可——**对策不是综合分析题的核心得分点**

**小马哥特别强调**：
- 不要脱离材料去谈个人看法——申论不是写议论文
- 如果实在找不到现成分析，就把材料中相关的句子改改写上去
- 综合分析题的得分点主要在"为什么"部分，不在"怎么办"

### 四、原因分析题

**核心逻辑**：找材料中所有"因为/由于/原因/根源/症结"相关的句子

**解题步骤**：
1. 扫材料，圈所有表示因果关系的词
2. 把原因部分摘出来
3. 合并同类项
4. 逐条列出

**小马哥特别强调**：
- 找原因要"往上一层"——材料说"工人工资低"，你要往上追：是"产业结构低端导致利润空间小"
- 但如果材料没有"往上一层"的信息，**就不要自己往上追**——只写到材料给到的层次

### 五、公文写作题

**核心逻辑**：格式对 + 要点齐 = 高分

**解题步骤**：
1. 看文种 → 调用格式模板（标题格式、有无称谓、有无落款）
2. 看题干中的写作目的 → 决定正文的核心内容方向
3. 从材料中找对应内容的要点
4. 把要点按逻辑排好塞进公文框架

**小马哥公文速成法**：
- **格式别丢分**：标题居中、称谓顶格、正文分段、落款靠右——格式对就有基础分
- **开篇三句话**：谁让你写的 + 为什么写 + 接下来要说什么
- **要点分条列**：一个要点一条，加序号，方便阅卷人找
- **结尾别啰嗦**：公文结尾一句话收住，不要抒情不要表态

**小马哥特别强调**：
- 提纲类公文不要写"的"字结构——直接写"一、背景：…… 二、做法：……"，不要写"一是明确了……""二是加强了……"之外的套话
- 讲话稿要注意身份感——你是代表谁在讲话，称谓要对
- 公文写作最怕"格式错 + 漏要点"，这两样抓好了分不会低

## 小马哥答题的"气质"

1. **直接** — 答案从材料中来，不多做加工
2. **朴素** — 语言平实，不用高大上的词，准确就行
3. **求全** — 宁可多写不少写，要点铺满
4. **务实** — 不追求文采，追求采分点不遗漏

## 小马哥答案的铁律：写在答题纸上的话，不是嘴里说出的话

**这是小马哥风格最容易出错的地方。** 小马哥上课时说话口语化，但他写在答题纸上的答案非常干净。模拟他的答案时，必须区分"讲课语言"和"答题语言"。

### 答题纸上绝对禁止的：
- **反问句**：❌ "一刀切的问题在哪？" → ✅ 直接写问题
- **设问句**：❌ "精确执法怎么做？" → ✅ 直接写做法
- **口语连接词**：❌ "所以/那么/你看/说白了/你想啊" → ✅ 删除，直接写
- **口语评价**：❌ "想怎么罚就怎么罚""群众不服气""图省事""这下好了" → ✅ 用材料原文描述
- **"的"字结构凑字数**：❌ "……的做法是值得借鉴的" → ✅ "……值得借鉴"

### 答题纸上的小马哥风格：
- 每条要点 = **主语 + 动词 + 宾语**，干净利落
- 要点之间用序号分隔，不加过渡句
- 宁可干巴巴，不要水汪汪
- 像在写提纲，不像在写文章

### 错误示例（综合分析题）：

**❌ 口语版（这不是答案！）：**
> 这句话讲的是执法要从"粗"变"细"。
> "一刀切"的问题在哪？S市化工厂严重超标罚几百，L区一袋过期食品罚上万——罚款没标准，想怎么罚就怎么罚，群众不服气。
> 所以这句话的核心是：执法不能只图省事"一刀切"。

**✅ 答题纸版（这才是答案）：**
> 这句话指出了行政执法从粗放式向精确执法的转型要求。
> 一、粗放式执法的弊端：行政处罚缺乏实体性裁量规则，导致罚款畸轻畸重。如S市化工厂严重超标仅罚几百元，L区一袋过期食品罚款上万元。
> 二、精确执法的内涵：认定讲证据——以事实为唯一依据；裁量讲道理——释法明理、法理相融；决定讲法律——在法律框架内精准适用。
> 三、执法目的不是处罚，而是提高法律遵从度、维护群众利益。

### 切换口诀

写完小马哥答案后，自问：
1. 有没有反问句/设问句？→ 有就删
2. 有没有"所以/那么/你看"？→ 有就删
3. 有没有口语评价词？→ 有就换成材料原文
4. 每句话能不能直接印在答题纸上不脸红？→ 不能就改

## 小马哥式答案质量标准

### 每条要点须满足"三不"：
- **不过度归纳**：材料说"缺乏资金"，你就写"缺少资金"，不要改成"资金保障不足"
- **不自我引申**：材料没说的一定不要写。即使你觉得某个对策很合理，材料没提就不能写
- **不写引入语**：开头直接列要点，去掉"针对XX问题，提出以下对策："

### 概括词也必须从材料中找（2026-05-17 补充）

**这是最容易出错的地方。** 小马哥的"适当归纳"意思是把材料中相似的词合并——比如"无高速出口""盘山路绕行"→归纳为"交通不便"。但**不能自创材料里没有的概括词**。

- ✅ 材料有"交通不便"→ 直接抄"交通不便"做概括词
- ✅ 材料说"盘山路+无高速出口"→ 归纳为"道路不连通"（近义提炼，考场上能写出）
- ❌ 自创"打通交通循环"——材料没有"循环"这个词
- ❌ 自创"产业凋敝""产业碎片化"——材料只有"产业单一""茶厂倒闭"
- ❌ 自创"集约基础设施""政务分割"——材料说"重复建设""不互通"

**概括词自检口诀**：写完每条概括词，问自己"材料里有这个词吗？"——没有就换成材料原词。

### 语言密度标准：
- 每条要点控制在 25-35 字
- 一个要点只说一件事
- 如果一条超过 40 字，拆成两条

### 错误示例 vs 正确示例：

**差（52字）：**
> 政府相关部门应当进一步加大对停车设施建设的财政支持与投入力度，从根本上解决群众反映强烈的停车位不足问题。

**好（28字）：**
> 将停车设施建设纳入城市更新专项资金，重点投向老旧小区。

**差（43字）：**
> 加强市民的绿色出行意识教育，引导市民尽量选择公共交通方式出行，降低私家车使用频率。

**好（22字）：**
> 优化公交微循环，引导短途出行向公共交通转移。

## 小马哥 vs 白鹭 核心差异

| 维度 | 小马哥 | 白鹭 |
|------|--------|------|
| 核心哲学 | "问啥答啥，有啥写啥" | "哪有我分析，还是概括你" |
| 审题 | 四项基本原则 | 题干四要素系统 |
| 找点 | 直接划线，圈关键词 | 8 类信号词 + 逻辑阅读法 |
| 归并 | 按领域归类（交通/人才/产业/民生），总括句+分类 | 就近合并 + 前置提炼 + 自拟概括词 |
| 概括题 | 观察材料行文顺序，区分"大哥""小弟" | 关键词阅读 + 逻辑阅读（总分留总、并分全丢） |
| 综合分析 | 是什么→为什么→怎么办（**非强制**，看材料偏向） | 3W 十六字方针（中好坏策，how 永不是重点） |
| 对策题 | 概括对策→借鉴对策→提出对策（三来源） | 问题→原因→对策（制度→执行→保障） |
| 应用文 | 格式对 + 要点齐 | 五把钥匙分层切入 |
| 语言 | 平实朴素，宁可干巴巴不要水汪汪 | 规范凝练，前置提炼词+材料关键词 |
| 适用场景 | 字数紧、要点散的题 | 需要归纳整合、逻辑重构的题 |
| 得分策略 | 求全求稳，不漏点 | 求深求准，逻辑见分 |
