# 2023年福建省公务员考试申论县乡卷

## 全卷概况

- **考试名称**：2023年福建省公务员考试申论县乡卷（2023多省联考）
- **试卷主题**：基层治理现代化与乡村产业振兴——材料1聚焦城市社区"村改居"治理创新（曾林社区），材料2聚焦乡村特色产业转型升级（L县山核桃）
- **给定材料概要**：材料1讲曾林社区以"近邻""聚邻""惠邻"三邻工作法推进"党建+"邻里中心建设，涵盖便民服务圈、养老服务、文化标识、红色网格、治理队伍、社群参与、卫健服务等方面。材料2讲L县山核桃产业从问题（质量参差/缺品牌/生态破坏/分散经营/加工薄弱）到转型升级（天目品牌/天生记龙头/生态修复/规模经营/脱蒲中心）的全过程。

## 各题详情

### 第1题

- **题型**：归纳概括题（概括做法）
- **分值**：15分
- **原题**：请根据"给定资料1"，谈谈曾林社区是如何做好"村改居"后半篇文章的。（15分）要求：全面、准确、有条理。不超过300字。
- **给定材料概要**：曾林社区是典型"村改社区"，以"近邻"为基、"聚邻"为要、"惠邻"为本，做优做实"党建+"邻里中心建设。近邻：按"去形式化、去机关化、去办公化"原则打造"一心多点"便民服务圈，引进政务一体机、便民联络卡、预约热线；建设居家养老服务照料中心，配备社区食堂、儿童之家、亲子阅读室等8个功能区，引进第三方运营；立足本土文化设计文化标识，建乡村记忆馆，推动大学生反哺基地、茶产学研基地落地，增设人才驿站。聚邻：推进红色网格化管理，建立"社区党组织—网格党小组—党员楼栋长—党员中心户"穿透式组织体系；建成二级网格党群服务站，驻点办公，日巡查，上门办；老带新帮带，建人才储备库，引入致和社工、亿家社工；线下设意见箱、轮值室、邻里会事厅，线上开通公众号留言板、微监督小程序。惠邻：共建卫生健康服务站，推动资源人员双下沉，一体化医疗卫生服务；服务活动常态化（20余场主题+60余场日常，4000+人次），绘制景观墙。
- **关键词**：曾林社区、村改居、近邻、聚邻、惠邻、党建+邻里中心、去形式化、便民服务圈、红色网格、穿透式组织体系、日巡查、人才储备库、卫生健康服务站、双下沉
- **阅卷采分点**：
  1. 近邻（空间+服务+文化）：去形式化/去机关化/去办公化 + 一心多点便民服务圈 + 政务一体机/联络卡/预约热线 — 3分
  2. 近邻：居家养老服务照料中心 + 8个功能区（食堂/儿童之家/亲子阅读室/早教托育中心）+ 引进第三方运营 — 2分
  3. 近邻：立足本土文化设计文化标识 + 乡村记忆馆 + 大学生反哺基地/茶产学研基地 + 人才驿站 — 2分
  4. 聚邻（网格）：红色网格化管理 + 穿透式组织体系 + 党员中心户/楼栋长联系群众 + 服务延伸至家庭 — 2分
  5. 聚邻：二级网格党群服务站 + 驻点办公 + 帮办代办前移 + 日巡查 + 上门办 — 1.5分
  6. 聚邻（队伍+平台）：老带新帮带 + 人才储备库 + 社工公益组织；线下意见箱/轮值室/邻里会事厅 + 线上公众号留言板/微监督小程序 — 1.5分
  7. 惠邻：卫生健康服务站 + 资源人员双下沉 + 就诊体检取药医保结算一体化 — 1分
  8. 惠邻：服务活动常态化（主题活动20余场/日常活动60余场/4000+人次）+ 绘制景观墙 — 1分

### 第2题

- **题型**：归纳概括题（概括问题+措施）
- **分值**：20分
- **原题**：请根据"给定资料1"，概括L县山核桃产业发展过程中存在的问题及解决措施。（20分）要求：全面、准确、有条理。不超过400字。
- **给定材料概要**：L县山核桃产业面临五大问题——①生产主体多、家庭作坊、质量参差不齐、以次充好（部门监管收效甚微）；②缺少品牌企业、多数代加工、利润薄品牌价值小；③种植规模无序扩张、过度用农药化肥致植被破坏水土流失品质下降；④种植成本上涨、分散经营致投入产出比下降；⑤加工储存环节薄弱（脱蒲汁液乱排、晒干存储不当影响品质）。对应五项措施——①发布"天目"区域公用品牌，委托省山核桃产业协会制定最高标准（炒制/手剥/山核桃仁三个标准），企业申请授权产品达标方可使用，市场监管部门不定期抽查，不合格撤销授权并向社会公布；②引进全国知名品牌"天生记"总部落户龙水镇，带动本地企业规范经营、现代化生产、市场营销、科技研发；③开展生态修复行动，退果还林2万亩由村集体看管，正常经营林推广自然落果、减少农药化肥使用；④推进林地流转，推广适度规模经营，利于机械化和数字技术利用，科学种植降本增效；⑤政府建设脱蒲中心，实行市场化运营，提供脱蒲、晒干、存储、销售一条龙服务，数字化管理仓储精准控温控湿。
- **关键词**：L县、山核桃、天目、天生记、家庭作坊、质量参差不齐、代加工、无序扩张、水土流失、投入产出比、脱蒲中心、数字化仓储、退果还林、自然落果、适度规模经营
- **阅卷采分点（问题）**：
  ① 生产主体多/家庭作坊/质量参差不齐/以次充好 — 2分
  ② 缺品牌企业/多数代加工利润薄/品牌价值小 — 2分
  ③ 无序扩张/过度农药化肥/植被破坏水土流失/品质下降 — 2分
  ④ 种植成本上涨/分散经营/投入产出比下降 — 2分
  ⑤ 加工储存薄弱（脱蒲汁液乱排/晒干存储不当） — 2分
- **阅卷采分点（措施）**：
  ⑥ 发布"天目"品牌 + 委托协会制定最高标准 + 企业申请授权达标方可使用 + 不定期抽查 + 不合格撤销公布 — 3分
  ⑦ 引进"天生记"总部 + 带动规范经营/现代化生产/市场营销/科技研发 — 3分（此分项含"天生记"专名0.5分）
  ⑧ 退果还林2万亩村集体看管 + 自然落果生态经营 + 减少农药化肥 — 2分
  ⑨ 推进林地流转 + 适度规模经营 + 机械化数字化科学种植 — 2分
  ⑩ 建设脱蒲中心 + 市场化运营 + 数字化管理仓储 + 一条龙服务 — 2分（此分项含"脱蒲中心"专名0.5分）
