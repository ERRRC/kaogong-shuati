# 2023年四川省公务员考试申论省市卷

## 全卷概况

- **考试名称**：2023年四川省公务员考试申论省市卷（2023多省联考，贵州A卷共用材料）
- **试卷主题**：A省农业高质量发展——涵盖棉花全产业链、北斗导航机械化、葡萄酒产业、骆驼产业链、塔河流域水资源改革五大领域
- **给定材料概要**：材料1讲述A省推进农业高质量发展的五项举措（棉花、机械化、葡萄酒、骆驼、水资源），材料2-4围绕乡村振兴、基层治理等主题展开。全卷主题聚焦农业现代化与乡村产业振兴。

## 各题详情

### 第1题

- **题型**：归纳概括题（概括做法）
- **分值**：15分
- **原题**：请根据"给定资料1"，归纳概括A省推进农业高质量发展的举措。（15分）要求：全面准确，条理清晰，语言简洁。不超过200字。
- **给定材料概要**：材料1包含五个段落，分别对应五大举措——①棉花全产业链：X县成立制种公司、轧花厂、纺织厂，建设高标准农田，50%棉花就地转化，规模化经营标准化生产机械化作业；②北斗导航机械化：Y县塔格村无人驾驶播种机播种冬小麦同步铺滴灌带，A省农作物综合机械化率87.5%；③葡萄酒产业：Z县夜光杯葡萄酒业获3项国际金奖，标准化栽培，线上线下销售，开发酒庄旅游，领办合作社带动千余户增收；④骆驼产业链：源旺生物科技生产驼奶/驼奶粉/驼绒制品/驼乳化妆品，科技深加工，布局骆驼小镇旅游康养文化一体；⑤水资源管理：塔河流域利用60年不遇洪水，6个分水枢纽引入农区林区，管理体制改革从供给侧向需求侧转变，80%洪水有效利用。
- **关键词**：A省、农业高质量发展、棉花、葡萄酒、北斗导航、机械化、骆驼、塔河、水资源、集群、全产业链
- **阅卷采分点**：
  1. 棉花全产业链：成立制种公司、轧花厂、纺织厂，就地转化纺织产品；建设高标准农田，规模化经营、标准化生产、机械化作业 — 3分
  2. 北斗导航机械化：无人驾驶播种机播种，同步铺设滴灌带；综合机械化水平达87.5% — 2分
  3. 葡萄酒产业：整合产业链上下游，标准化栽培，研发系列产品，线上线下销售，开发酒庄旅游业态，领办合作社带动农民增收 — 3分
  4. 骆驼产业链：生产驼奶/驼奶粉/驼绒制品/驼乳化妆品，科技深加工；布局骆驼小镇，旅游康养文化一体 — 3分
  5. 水资源管理改革：利用洪水通过分水枢纽引入农区林区；从供给侧向需求侧转变，深入灌区保障需求 — 3分
