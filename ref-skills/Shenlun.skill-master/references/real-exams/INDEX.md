# 申论真题知识库索引

## 匹配规则

1. 从用户OCR内容中提取实体词（地名、机构名）、主题词（反复出现的核心概念）、结构词（"第X题""XX分"）
2. 将提取的关键词与下表中每行的"主题关键词"列做交集比较
3. 按重叠数量判定：
   - **>=3 个关键词重叠** → 高置信度匹配，直接告知用户并加载对应真题文件
   - **1-2 个关键词重叠** → 中等置信度，向用户确认"检测到您的题目可能是【XX年XX卷 第X题】，是否正确？"
   - **0 个关键词重叠** → 未匹配，使用通用评估流程，事后询问用户是否添加到库
