# 2022年福建省公务员考试申论省市卷

## 全卷概况

- **考试名称**：2022年福建省公务员考试申论省市卷（2022多省联考，7月9日）
- **试卷主题**：城乡融合中"人"的连接作用——全卷4则材料分别用四个案例论证同一个主题
- **给定材料概要**：材料1讲M市"巧阿姨"家政品牌（农村妇女进城，农村→城市流向）；材料2讲95后小周"乡情优选驿站"（城市返乡，城市→农村流向）；材料3讲璧云区"四城"建设（生态、文化、活力、幸福之城）；材料4讲远山农庄和依水村"文艺村落"（城乡双向奔赴）。全卷核心命题：**"城市和农村从来都不是隔断的……仍需要连接的纽带——人。"**

## 各题详情

### 第1题

- **题型**：综合分析题（理解分析类——"谈谈为什么说"）
- **分值**：20分
- **原题**：根据"给定资料1"，请你谈谈为什么说"'巧阿姨'搭建了城乡交流的桥梁，串起了城和乡"。（20分）要求：分析全面，条理清晰。不超过400字。
- **给定材料概要**：材料1讲述了M市打造"巧阿姨"家政品牌的完整故事。郭玲（阳光职业学校校长）发现城市家政市场需求大→回乡创业培训农村妇女；小李（首批"巧阿姨"）从月子中心到住家月嫂，薪资稳步增长，"见识了外面的世界""成了家里的顶梁柱"；梅主任评价"好阿姨是稀缺资源""专业、有韧性、有创造力"；刘副市长介绍年务工收入近30亿元、收入用于子女教育带来深远影响、写入"十四五"规划打造全国标杆；张主任介绍与北京上海高职院校合作、面向社会招生、打造中高端人才基地；孙研究员点题："巧阿姨搭建了城乡交流的桥梁，串起了城和乡"。材料还提到家政需求从传统保洁做饭拓展到育儿早教、养老护理等多元化业态，从业人员年轻化、文化水平越来越高。
- **关键词**：巧阿姨、M市、家政服务、城乡交流、桥梁、农村妇女、培训、增收、品牌、标准化、多元化需求、十四五、中高端人才基地
- **阅卷采分点**：
  1. 培训赋能乡村端：开阔视野增长见识(1.5) + 提升家政服务能力(1) + 适应城市环境融入城市生活(1.5) + 成功上岗收入翻番改善家庭生活(2) = 6分
  2. 对接城市需求端：年轻人忙需求量大(1) + 需求覆盖面越来越广(1) + 从保洁做饭拓展到育儿早教养老护理多元化(2) + 对服务质量要求越来越高(1) = 5分
  3. 政府制度推动：审时度势纳入十四五规划(1) + 打造巧阿姨品牌全国家政标杆(1) + 培训标准化科学化长效化(1) + 引导行业协会龙头企业培训机构职业院校深度合作(1) + 面向社会招生与京沪合作打造中高端人才基地(1) = 5分
  4. 双向互动桥梁本质：家政市场缺口大为剩余劳动力转移提供广阔空间(1) + 妇女增收致富收入反哺子女教育深远影响(1.5) + 材料点题句"搭建城乡交流桥梁串起城和乡"(1.5) = 4分

### 第2题

- **题型**：公文写作题（宣传稿）
- **分值**：30分
- **原题**：假如你是璧云区委宣传部的一名工作人员，请根据"给定资料3"，拟写一篇反映璧云区"四城"建设成就的宣传稿。（30分）要求：（1）紧扣资料，内容全面；（2）条理清晰，语言生动；（3）不超过500字。
- **给定材料概要**：材料3讲述璧云区自2017年确定"四城"建设目标以来的成果——生态之城（云巴空中有轨电车、35座生态公园68个生态广场、"推窗见绿出门见景"）；文化之城（城市记忆工程、文艺精品工程、古村落茶铺状元桥等传统文化元素、千年文脉）；活力之城（"璧云人才"APP、评选璧云英才/工匠/创客、智能制造新能源、国际半程马拉松、西部动漫节、产城融合）；幸福之城（"出生一件事"特色服务、三泉康养小镇、智慧养老云平台、"高端有引领社会有服务兜底有保障"养老体系、15个镇街养老服务中心45个社区养老服务站54个村级互助养老点）。
- **关键词**：璧云区、四城建设、宣传稿、生态之城、文化之城、活力之城、幸福之城、云巴、公园、城市记忆、人才、产城融合、出生一件事、康养小镇

### 第3题

- **题型**：大作文
- **分值**：50分
- **原题**：请结合给定资料，以"城·乡·人"为题，联系实际，自选角度，写一篇文章。（50分）要求：（1）观点明确，见解深刻；（2）参考给定资料，但不拘泥于给定资料；（3）思路清晰，语言流畅；（4）总字数1000—1200字。
- **给定材料概要**：全卷4则材料均围绕"人连接城乡"展开——材料1巧阿姨（农村妇女→城市家政服务）、材料2小周乡情优选驿站（城市青年→农村数字纽带）、材料3璧云区（城市品质建设吸引人才）、材料4远山农庄和依水村（城乡双向奔赴，城市人下乡创业、共建"乡村生活共创集群"）。材料2点出核心："城市和农村从来都不是隔断的，互联网的下沉建立了数字城乡通道，但仍需要连接的纽带——人。"材料4收束："建立一条连接'故乡'的纽带，实现故乡的梦想，找到梦想的故乡。"
- **关键词**：城·乡·人、城乡融合、连接纽带、巧阿姨、小周、璧云区、远山农庄、依水村、双向流动、乡村振兴、人才、数字化
- **主题类型（袁东框架）**：多主题组合型——"城""乡""人"三个概念，"人"是连接"城"与"乡"的核心纽带，前两者通过第三者实现融合
- **分论点方向**：
  1. 人连接城乡经济发展：劳动力流动（巧阿姨进城）、消费对接（远山农庄农产品直销）、产业带动（依水村创业集群）
  2. 人连接城乡生活方式：数字化下沉（小周教老人网购视频）、公共服务均等化（璧云区养老体系）
  3. 人连接城乡情感交流：乡情纽带（小周帮留守老人与外出子女互通有无）、故乡记忆（远山农庄主打"小时候妈妈做的菜"）
- **阅卷采分点**：
  1. 立意准确："人"是连接城乡的核心纽带，不偏离三者关系 — 15分
  2. 结构清晰：3个分论点各自独立、逻辑递进 — 10分
  3. 论证充分：每个分论点有材料案例支撑且适当拓展 — 10分
  4. 语言表达：标题点题、语言规范流畅 — 7分
  5. 结合材料：紧扣4则给定资料，不脱离材料空谈 — 8分
