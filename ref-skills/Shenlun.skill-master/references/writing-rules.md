# 小题作答铁律与版本差异

## 一、作答铁律（7条）

### 1. 字数铁律

- 严格控制在题目字数上限的 85%-95%
- 单条要点不超过 40 字

### 2. 句子结构铁律

每条要点 = 动词短语 + 具体对象 + 结果/目的。不写"要""应该""需要"等情态动词。

- 差："政府应该加大对停车设施的财政投入力度"
- 好："将停车设施建设纳入城市更新专项资金，重点投向老旧小区改造"

### 3. 去水铁律

删除无意义短语："在……的过程中""不断""进一步""加大力度""高度重视""充分认识"。不写"穿靴戴帽"的引入句和总结句。

### 4. 概括词铁律

**概括词必须来自材料，禁止自创。** 材料有原词直接抄。白鹭的"前置提炼"也是从材料已有词汇中选一个做概括词。

- 自检："材料里有这个词吗？"没有就换成材料原词。
- 禁止自创四字术语（如"打通交通循环""产业凋敝""政务分割"等材料没有的词）

### 5. 建议不写问题细节

问题和建议分开呈现时，建议部分不重复问题中的具体细节。问题已写"无高速出口、绕几十里盘山路"，建议只写对策。

### 6. 不写无采分点废话

不写"借鉴XX做法""借鉴XX经验""参考XX模式"——除非题目明确要求。这些短语在采分点上得不了分。

### 7. 每句自检

写完答案逐句问："这一句能在采分点上得分吗？"不能就删。

## 二、两个版本的差异定位

两版都用材料原词，差异仅在：

| | 小马哥版 | 白鹭版 |
|------|------|------|
| 概括词 | 直接用材料原词（"交通不便""产业单一"），不做提炼 | 可做近义提炼（"道路不连通""产业缺乏统筹"），但不自创材料没有的词 |
| 语言 | 更干更短，动词+宾语直接走，不串联 | 加少量轻串联使条与条之间更通顺 |
| 结构 | 问题+建议融合在每条里 | 同左，结构不另起炉灶 |

## 三、材料分析信号词

**8 类信号词**：首位位置、最高级（最/根本/关键）、递进词（更/值得/进一步）、转折词（但/然而）、并列词（同时/另外/序号）、结论词（这些/所以/因此）、引出观点的词（某某表示/指出）、特殊符号（冒号看前/破折号看后/引号强调/分号并列）

**逻辑阅读**：总分关系→留总不留分；并分关系→全留或全丢

**踩点补救**：主题词定位、高频词圈定（>2次）、首尾相接（大长句逗号单位首尾相连）
