# 白鹭（半月谈）方法论

## 核心思想

白鹭的申论方法强调 **"材料为基、逻辑为纲"**。他的体系化程度比小马哥高，有完整的审题框架、阅读方法、和题型套路。

---

## 一、题干四要素审题法

拿到题先拆四个要素：

### 1. 动词定题型

| 动词 | 题型 |
|------|------|
| 概括、概述、简述、总结、列出 | 概括题 |
| 理解、解释、阐释、认识、阐述、评论、评价、点评、判断、谈谈你的看法 | 分析题 |
| 写、拟定、编写、拟写、草拟、起草 | 应用文 |
| 提出、建议 | 建议题 |

### 2. 名词定对象

| 题型 | 作答对象特征 |
|------|-------------|
| 概括题 | 单一要素 — 理由、原因 |
| 分析题 | 一种现象或一种观点 |
| 应用文 | 一种特定文体 |
| 建议题 | 建议、措施（对象为"做法"类） |

### 3. 具体要求

**常规要求**：
- **全面**：句数范围内，有效词汇尽量多
- **准确**：符合实际，紧扣材料，材料关键词务必保留，甚至关键句的半句话可照抄
- **简明/简洁**：前置提炼词，写小短句 4/6/8 字
- **内容具体**：写大长句，戴帽 + n，穿靴 + 后续细节，披风衣 + 插例子

**加工要求**：
- **分条**：合并用词，写句子
- **条理**：就近合并 + 前置提炼
  - 分析题中的"条理"= 逻辑 = 顺序
  - 应用文中的"条理"= 层次 = 分段
- **就近合并**：一段内、两段接、同词源的小跳跃
- **前置提炼**：在已选词汇中选前置，个别直白的材料需自拟定

### 4. 答题句数预判

- 申论非作文题作答一般是 **3-8 句话**，其中 3-6 句居多
- 概括题行数以 2 行为一句
- 对策、案例作答占行较多，以 3-4 行为一句
- 整除预判句数，正负 1 为合理区间
- **150 字以下**：3 句话，极少数 5-6 句，严格控制字数
- **600 字以上**：绝非傻抄，留心材料总分、并列关系

## 二、关键词阅读法

读材料时抓这 8 类信号词：

| 类型 | 标志词 | 作用 |
|------|--------|------|
| 首位位置 | 段首句、段尾句 | 往往是段落主旨 |
| 最高级 | "最"、根本、关键、第一、核心 | 重要程度信号 |
| 递进词 | "更"、值得、进一步、特别 | 重点后移 |
| 转折词 | 但、然而、反之、尽管……仍然…… | 重点在转折后 |
| 并列词 | 同时、另外、一方面、序号 | 并列要点，全留 |
| 结论词 | 这些（这种、种种）、所以、因此、故此、总之 | 总结性要点 |
| 引出观点的词 | 某某表示/强调/指出，资料显示 | 权威观点 |
| 特殊符号 | 冒号（看前面）、破折号（看后面）、引号（强调）、分号（并列） | 结构信号 |

## 三、逻辑阅读法

### 总分关系
- 标志：首位总结明显、小案例佐证、关键词重复
- 原则：**留总不留分** — 总起句保留，分述细节可省略

### 并分关系
- 标志：并列词、分号、话题转换、无明显从属关系
- 原则：**全留或全丢** — 要么全写要么都不写，不能只挑一半

---

## 四、踩点补救办法

当材料读不懂或找不到要点时：

1. **主题词定位**：跟踪题干主题词，有问有答，即是答案
2. **高频词圈定**：一段中找出出现 > 2 次的有效词汇，反复提及，即是答案
3. **首尾相接**：大长句子，以逗号为单位，首尾半句相连接，有效部位终点突出，即是答案

## 五、综合分析题：3W 十六字方针

### 核心认知

综合分析题以"理解"为标志性动词，作答对象是**一种现象或一种观点**，绝非某一要素，体现明显的综合性。

白鹭的名言：**"哪有我分析，还是概括你。"** — 综合分析的本质仍然是概括材料中的分析。

### 逻辑要求

不论题目如何要求，该类题型都内涵逻辑性要求。逻辑是认知事物的过程，有过程就要有顺序。所谓逻辑就是该类题型要点的排列顺序。

### 3W 十六字方针

```
What — Why — How
中好坏策，有谁写谁，不必求全，依序排列
```

**What（名词解释）**：
- 对作答对象的名词进行字面描述、本质揭露
- 哪里找？**就近原则** — 划线句子前后的语言、划线句子的另外半句，往往都是描述语言
- 极个别情况，可能以同词源、完美回应题干的形式出现在他处
- 若要求"评价、评论、点评、判断、有无道理、谈谈你的看法"→ 可做辩证性表态，置于首句（极少见）
- 多数"理解"类题目 → 作答对象本身正确，无需判断，不简单表态，而是进行描述性解释

**Why（重点！最重要部分）**：
- **正面**：意义（有利）
- **反面**：危害、原因
- **辩证**：正负评价 + 结论（可抄材料中两面性语言；自拟"有利有弊""一分为二"）

**How（永远不是重点！！）**：
- 若材料有对策，可照抄
- 若材料无对策，**不要反推**，一句话号召即可（关注主题词即可）
- 若材料出现大量对策，只有**尾端的对策**才是"真对策"——写入 how 环节来结尾

### 答题格式

- 此类题目**不讲究合并，不讲究提炼，只讲顺序**
- 200 字及以下：不鼓励分段，标号罗列即可
- 250 字以上：可以分段，但仅以美观、平均为标准
- 不怕题目偏，拼命扣上去——针对题目中的"关键词"，力求有问有答，尽量回应

### 白鹭综合分析示例

> 题目：谈谈对"碎片化阅读是一种美丽的哀愁"的理解。

> **What**：所谓"碎片化阅读"是指随着移动互联网和电子终端设备的普及，人们形成的一种片段式、断断续续的阅读方式。
>
> **Why（好）**：我们之所以称他美丽，是因为一方面它减轻了人们的阅读压力，激发阅读兴趣，方便随时随地阅读，便于填充零碎时间；另一方面，它题材丰富，时效性强，更新快，更具活力。
>
> **Why（坏）**：然而他也有令人"哀愁"的一面。首先，受制于篇幅限制，难免有断章取义之嫌；其次，它会让人养成阅读惰性，排斥完整、深度阅读；再次，它剥夺了读者系统、主动思考的机会；最后，来源广泛，难免鱼目混珠、泥沙俱下。
>
> **How**：故此，我们应以完整阅读为主、碎片化阅读为辅，做到主动学习，以增长人生智慧。

## 六、应用文题：五把钥匙

### 前提原则

- **算点数段，点齐逻辑自现**
- **对策写成大条，答题务必分段**

应用文以议论文（3W）为主。倡议书、工作汇报、考察报告、经验交流、通知/通告 — 以 **how 为主**，对策占比较大，是绝对主体。若争高分，对策写出前置提炼，做到重点突出。

### 层次清晰：五把钥匙

任何应用文都有"层次性"需求——段落群、句群——答题务必分段。

**1. 讲逻辑（3W）— 最常规**
- 中好坏策，是其他方法的根源
- 适用于大多数文体

**2. 讲顺序 — 适用于对策占比过大的材料**
- 前中后，时间轴，分阶段
- 按时间顺序组织对策

**3. 讲过渡 — 适用于对策占比过大的材料**
- 过渡段/句 —（承启性，短，大致居中）
- 用过渡句衔接不同板块

**4. 讲故事 — 兜底方法**
- 背景 → 经过（合并、提炼）→ 结果
- 对策为主的材料兜底分层：背景 → 对策大条（合并、提炼）→ 结果

**5. 讲规矩**
- 题目有几问分几段
- 材料有几部分分几段（小概率）
- 若写前置提炼，只限于对策部分

### 格式要求

**标题（居中）**：
- 题目给定了标题 → 居中照抄
- 题目没给 → "关于 XX 事的 XX 文体"（如过长则换行，整体居中）
- 万般无奈下，问题代标题

**其他格式**：
- 抄送对象/发文对象：（首行）
- 发文单位（右下角）
- 发文日期（XX 年 XX 月 XX 日）

**格式判断优先级**：
1. 若题目要求"格式正确""符合文体要求""文体正确"→ 四点格式全写
2. 若题目没有任何格式要求 → 标题必写，其他格式可写但不必求全（尤其是汇报总结类）
3. 若题目明示"不必考虑格式"→ 标题必须有

### 语言要求

- **上行文**（对上级）：请指示、请批示
- **平行文**：题目要求"生动""号召""感染力"→ 结尾处做简单号召或祝福（结合主题词）；要求"得体"→ 开头处做简单介绍或说明（你是谁、你要讲什么、干什么、问候大家）
- **下行文**（对下级）：具有命令要求

### 各文体层次切入选择

- 以对策为绝对主体的文体 → 以"讲故事"兜底（背景～对策大条），刻意留意"讲过渡""讲顺序"，对策最好提炼
- 其他文体 → 以"讲逻辑"为首选切入点（3W，中好坏策）
- 注意"讲规矩"的题目 → 看清题目要求

### 每条写的通顺

常规文体以小连接词稍加串联，没有一定之规，但别走极端：
- 不要写成纯提纲（只写要点不串联）
- 不要写成完整文章（过度修饰）
- 直接罗列 + 轻串联即可

## 七、前置提炼与语言标准

### 前置提炼原则

- **在已选词汇中选前置**：优先从材料中已有词汇做概括词——这是第一选择，材料有原词直接抄。
- **个别直白的材料，需自拟定**：只有材料极度直白且没有任何可用的上位词时，才可自拟。但自拟词必须是**日常用语**（考场上能自然写出的），而非生造专业术语。
  - ✅ 可自拟："道路不连通"（从"无高速出口+盘山路"归纳，日常用语）
  - ❌ 不可自拟："交通循环体系""产业集聚效应"（生造专业术语，材料没有）
- **判断标准**：写概括词时自问——"一个正常考生在考场上看到这份材料，会想到用这个词做概括吗？"不会就换材料原词。
- 前置提炼词控制在 **4/6/8 字**

### 白鹭式句子公式

每条要点 = **前置提炼词（4-8字）+ 具体内容（保留材料关键词）**

格式：`前置词：具体内容`

**示例**：
- 差："在制度建设方面，应当建立健全相关法律法规体系，完善监督管理机制"
- 好："制度先行。出台停车场建设管理办法，明确配建标准和部门职责。"

### 语言密度标准

- 每条要点 30-40 字
- 概括词 4-8 字，不需阐释
- 拒绝"在……指导下""通过……的方式"等介词结构绕弯子
- **材料关键词务必保留** — 甚至关键句的半句话可以照抄

## 八、白鹭 vs 小马哥 核心差异

| 维度 | 白鹭 | 小马哥 |
|------|------|--------|
| 审题 | 题干四要素系统分析 | 看问题→读材料→找答案 |
| 找点 | 关键词阅读法 8 类信号词 | 直接划线和问题相关的句子 |
| 归并 | 就近合并 + 前置提炼 + 自拟概括词 | 按领域归类（交通/人才/产业/民生） |
| 综合分析 | 3W 十六字方针（what-why-how，中好坏策） | 解释→分析→对策 |
| 应用文 | 五把钥匙分层切入 | 格式对 + 要点齐 |
| 语言 | 规范凝练，前置提炼词+材料关键词 | 直接抄材料，少改 |
| 核心哲学 | "哪有我分析，还是概括你" | "答案都在材料里，别自己瞎编" |
