## 题目

第五题（35分）

“给定资料5”中提到“城市更新，更新的是设施，温暖的是民心”，这句话引发了你怎样的思考？请结合全部给定资料，联系实际，自选角度，自拟题目，写一篇议论文。

要求：
1. 观点明确，见解深刻；
2. 参考给定资料，但不拘泥于给定资料；
3. 思路清晰，语言流畅；
4. 字数1000—1200字。

## 给定资料1

“这日子啊，就像这星河水一样，越过越有奔头！”初冬清晨，星河镇沿溪村村民李大姐一边晾晒腊肉，一边笑着招呼前来采风的文艺工作者。沿溪村坐落在青峰山麓，一条星河穿村而过，曾经因地处偏远、产业单一，是远近闻名的贫困村。近年来，村里依托山水资源发展生态文旅，实现了从贫困村到网红村的蝶变。

变化始于2019年的“千万工程”深化推进。沿溪村不搞大拆大建，坚持“保留肌理、修旧如旧”，对古民居进行微改造：黄泥墙、木格窗保留原有风貌，内部加装厨卫、供暖等现代化设施；废弃的老粮仓改造成村史馆、非遗工坊；晒谷场翻新为文化广场，定期举办民俗活动。村里还打通了环山步道，串联起瀑布、古寺、竹海等自然人文节点，打造“一步一景”的慢行系统。

产业是乡村振兴的根基。沿溪村探索“村集体+公司+农户”模式，统一运营民宿、农家乐、农产品销售。村集体以山水资源、集体资产入股，占股30%；文旅公司负责品牌运营、客源引流，占股40%；村民以房屋、土地、劳动力入股，占股30%。村民既能获得务工收入、土地租金，还能参与年底分红。2023年，村集体收入突破200万元，村民人均可支配收入达到3.2万元，比2018年翻了两番。

人才回流为乡村注入活力。村里出台“乡贤回归”政策，搭建创业孵化平台，提供场地补贴、贷款贴息、技能培训等支持。在外从事设计工作的返乡青年小周，牵头打造了“星河礼物”文创品牌，将竹编、蜡染等非遗技艺融入文创产品，线上线下同步销售；学农业的大学生小陈，回乡创办生态农场，推广有机种植，打造采摘研学基地，带动20多户村民就业。

“乡村振兴不是把城市搬到农村，而是让农村更像农村，让农民过上好日子。”星河镇党委书记说，“我们守住了绿水青山，也换来了金山银山，更留住了乡愁与烟火气。”

## 给定资料2

耀州市是传统制造业大市，拥有装备制造、纺织服装、家居建材三大支柱产业。近年来，受市场需求变化、成本上升等因素影响，传统产业增速放缓，转型升级迫在眉睫。为此，耀州市启动“产业焕新”行动，推动传统制造业向高端化、智能化、绿色化转型。

在装备制造领域，当地龙头企业重工集团投入12亿元建设智能工厂，引入工业机器人、数字孪生系统，实现生产全流程可视化管控。改造后，人均生产效率提升65%，产品不良率下降42%，订单交付周期缩短30%。企业还联合高校共建高端装备研究院，攻克了多项核心零部件技术，打破国外垄断，产品出口到30多个国家和地区。

纺织服装产业曾以代工贴牌为主，利润微薄。耀州市引导企业向品牌化、定制化转型，建设行业级工业互联网平台，连接上下游200多家企业。平台整合订单、产能、物料数据，实现按需生产、柔性制造；企业通过大数据分析消费者偏好，开发个性化定制服务，客户下单后7天即可交付成品。一批本土品牌快速崛起，线上销售额占比从2019年的18%提升到2023年的56%。

绿色转型也是重要方向。耀州市出台节能降碳专项政策，对企业技改给予补贴，推广清洁能源、循环生产模式。家居建材行业全面推行清洁生产，窑炉废气回收利用、废水闭环处理，万元产值能耗下降32%；多家企业建成“零碳工厂”，余热发电、光伏屋顶等项目广泛应用。2023年，全市规模以上工业企业单位能耗同比下降8.3%，绿色制造体系初步建成。

“传统产业不是落后产业，也不是夕阳产业，只要找准转型路径，就能焕发新生机。”耀州市工信局局长表示，下一步将持续强化创新驱动，完善产业生态，推动传统产业向价值链高端攀升。

## 给定资料3

“以前办个企业开办手续，要跑工商、税务、社保好几个窗口，没个三五天办不完。现在进一个门、交一套材料，半天就全部搞定了。”在陵江市政务服务中心，刚办完营业执照的企业负责人王先生感慨道。

近年来，陵江市以“高效办成一件事”为抓手，纵深推进“放管服”改革，打造一流营商环境。当地将企业开办、项目审批、不动产登记等高频事项整合成“一件事”，实行“一表申请、一窗受理、一网通办、一次办结”。企业开办环节从7个压缩到1个，办理时间从3个工作日压缩到0.5个工作日；工程建设项目审批时限从120个工作日压减至45个工作日以内。

数据共享是改革的核心支撑。陵江市打通了23个部门的业务系统，归集186类政务数据，实现电子证照、审批结果跨部门互认共享。群众办事无需重复提交身份证、营业执照等材料，系统自动调取核验。全市98%的政务服务事项实现“网上可办”，85%的事项实现“全程网办”，高频事项基本实现“跨省通办”“省内通办”。

针对企业发展中的痛点堵点，陵江市建立“企业诉求直达机制”。企业通过政务服务平台、企业服务专线反映问题，实行“一口受理、分类转办、限时办结、回访评价”。一般诉求24小时内响应，复杂诉求7个工作日内答复。2023年共受理企业诉求3200余件，办结率99.2%，企业满意度96.8%。

改革不仅方便了企业群众，也提升了政府治理效能。通过流程再造、数据赋能，政务服务人力成本下降30%，审批差错率大幅降低。“营商环境没有最好，只有更好。”陵江市政务服务管理局负责人表示，将持续深化改革，推动政务服务从“能办”向“好办、快办、智办”升级。

## 给定资料4

北河省是农业大省，粮食产量连续多年稳居全国前列。但长期以来，农业产业链条短、附加值低、品牌影响力弱等问题突出。近年来，北河省大力实施“农业全产业链提升工程”，推动农业从“卖原料”向“卖产品”“卖品牌”转变。

在粮食主产区安平县，当地引进多家粮食深加工企业，将小麦加工成专用面粉、挂面、速冻食品，玉米加工成淀粉、饲料、生物制剂，粮食附加值提升3倍以上。全县形成了“种植—收储—加工—销售”完整产业链，带动农户1.2万户，户均年增收8000余元。

农产品冷链物流体系建设同步推进。北河省投入专项资金，在主产区建设产地预冷、仓储保鲜设施，在销区布局冷链配送中心，打通农产品出村进城“最初一公里”和“最后一公里”。以前蔬菜、水果采摘后损耗率高达25%，现在全程冷链运输，损耗率降至8%以下，错峰销售还能提升售价20%—30%。

品牌培育是关键一招。北河省整合区域特色农产品，打造“北河农品”省级公共品牌，实行统一标准、统一标识、统一推广。遴选优质企业授权使用品牌，严格质量管控，建立溯源体系，消费者扫码即可查看种植、加工、运输全流程信息。目前，全省已有60多家企业、200多款产品纳入公共品牌体系，市场认可度持续提升。

此外，当地还大力发展休闲农业、乡村旅游，推动农文旅融合。依托现代农业产业园、特色种植基地，打造观光采摘、农事体验、民宿餐饮等业态，拓展农业多种功能。2023年，全省休闲农业接待游客超2亿人次，综合收入突破800亿元，成为农业农村经济新的增长点。

## 给定资料5

“我们的城市，不仅要有高楼大厦，更要有烟火温度。”在云州市城市更新工作会议上，市委主要负责人这样强调。近年来，云州市稳步推进城市更新行动，不搞大规模拆迁重建，而是聚焦老旧小区、老街巷、老厂区改造，补齐民生短板，保留城市记忆，让老城区焕发新活力。

始建于上世纪80年代的幸福里小区，曾经设施老化、环境杂乱、停车困难。2022年纳入老旧小区改造后，小区不仅翻新了外立面、修缮了道路、新增了停车位，还配套建设了养老驿站、便民食堂、儿童活动中心、智能快递柜等服务设施。“以前总想着换房子，现在小区改造完，住着比新小区还舒服，舍不得搬走了。”小区居民张阿姨说。

历史文化街区的改造同样注重“留形留魂”。百年老街升平街改造中，当地坚持“修旧如故”，保留了骑楼、石板路、老字号商铺等历史风貌；同时引入文创店铺、特色餐饮、非遗体验等新业态，打造“老城市、新消费”场景。改造后的升平街既保留了老云州的烟火气，又成为年轻人喜爱的打卡地，节假日日均客流量超过3万人次。

老工业厂区也实现了华丽转身。原纺织厂旧址保留了厂房建筑、生产设备等工业遗存，改造为文创产业园，引入设计工作室、艺术展厅、剧场、书店等业态；原钢铁厂部分厂区改造为工业遗址公园，配套建设运动场地、休闲步道，成为市民休闲健身的好去处。工业遗产“腾笼换鸟”，既留住了城市工业记忆，也催生了新的经济业态。

城市更新，更新的是设施，温暖的是民心。云州市在改造中充分征求群众意见，通过居民议事会、线上问卷等方式，让群众说了算、一起干。“城市更新不是政府单方面的事，而是全体市民共同的事业。只有把群众需求放在首位，才能真正改到群众心坎上。”市住建局负责人说。
