## 给定资料2

耀州市是传统制造业大市，拥有装备制造、纺织服装、家居建材三大支柱产业。近年来，受市场需求变化、成本上升等因素影响，传统产业增速放缓，转型升级迫在眉睫。为此，耀州市启动“产业焕新”行动，推动传统制造业向高端化、智能化、绿色化转型。

在装备制造领域，当地龙头企业重工集团投入12亿元建设智能工厂，引入工业机器人、数字孪生系统，实现生产全流程可视化管控。改造后，人均生产效率提升65%，产品不良率下降42%，订单交付周期缩短30%。企业还联合高校共建高端装备研究院，攻克了多项核心零部件技术，打破国外垄断，产品出口到30多个国家和地区。

纺织服装产业曾以代工贴牌为主，利润微薄。耀州市引导企业向品牌化、定制化转型，建设行业级工业互联网平台，连接上下游200多家企业。平台整合订单、产能、物料数据，实现按需生产、柔性制造；企业通过大数据分析消费者偏好，开发个性化定制服务，客户下单后7天即可交付成品。一批本土品牌快速崛起，线上销售额占比从2019年的18%提升到2023年的56%。

绿色转型也是重要方向。耀州市出台节能降碳专项政策，对企业技改给予补贴，推广清洁能源、循环生产模式。家居建材行业全面推行清洁生产，窑炉废气回收利用、废水闭环处理，万元产值能耗下降32%；多家企业建成“零碳工厂”，余热发电、光伏屋顶等项目广泛应用。2023年，全市规模以上工业企业单位能耗同比下降8.3%，绿色制造体系初步建成。

“传统产业不是落后产业，也不是夕阳产业，只要找准转型路径，就能焕发新生机。”耀州市工信局局长表示，下一步将持续强化创新驱动，完善产业生态，推动传统产业向价值链高端攀升。
