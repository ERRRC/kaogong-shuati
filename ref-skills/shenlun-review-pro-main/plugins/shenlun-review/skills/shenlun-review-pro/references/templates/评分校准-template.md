# 评分校准模板

本模板定义评分校准记录结构。当有官方答案、教师点评或自我复核时写入。

```yaml
原始评分_batch_id: 关联的作答批次
原始评分_seq: 关联的作答序号
校准日期: YYYY-MM-DD
校准来源: 官方评分/教师点评/自我复核
原始分数区间: [低分-高分]
原始分数中心: X
校准分数: X
校准偏差: X - 原始中心
偏差原因分析: |
  分析偏差原因，例如：
  - 等义要点判定差异
  - 维度权重理解不同
  - 材料要点提取范围不同
维度调整: （如有权重变更，记录具体调整）
```

## 使用场景

1. **官方评分**：用户获得官方评分后，记录偏差并分析原因
2. **教师点评**：教师给出分数或反馈后，记录并对比
3. **自我复核**：用户重新审视评分后，记录复核结论

## 写入规则

- 文件路径：`<状态根>/评分校准/<batch_id>-<seq>-calibration.md`
- 仅在有实际校准来源时写入，不凭空创建
- `偏差原因分析` 必须具体，不写空泛描述
- 校准记录可累积，每次校准追加新记录

## 校准学习

- 积累多条校准记录后，可分析系统性偏差
- 例如：某维度持续高估或低估
- 这些发现可反馈到方法卡的 `修改动作` 字段
