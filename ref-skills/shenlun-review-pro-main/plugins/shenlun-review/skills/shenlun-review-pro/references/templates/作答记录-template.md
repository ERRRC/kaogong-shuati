# 作答记录模板

本模板定义单次作答评分的完整记录结构。每次评分完成后由系统自动写入。

```yaml
batch_id: 批次标识
seq: 序号
题型: 归纳概括/综合分析/提出对策/贯彻执行/申发论述
任务摘要: 一句话概括题目要求
材料段落数: N
作答字数: 约 X 字
评分日期: YYYY-MM-DD
建议档位: [档位描述]
分数区间: [低分-高分]
分数中心: X
置信度: 高/中/低
置信度依据: [具体说明]
参考答案来源: 官方/机构/教师/无
```

## 分项评分

```yaml
分项评分:
  - 维度: 任务符合
    层级: 0-4
    诊断得分: X.XX
    备注: 具体说明
  - 维度: [下一维度]
    层级: 0-4
    诊断得分: X.XX
    备注: 具体说明
```

## 要点覆盖表

```yaml
要点覆盖:
  - 要点序号: 1
    要点内容: 一句话描述
    覆盖状态: 完整覆盖/部分覆盖/等义表达/未覆盖/超出材料
    材料来源: 段落 X / 句 Y
    用户表述: 用户原句或概括
```

## 得失分分析

```yaml
做得好的:
  - 维度: xxx
    说明: 具体好在哪里

主要失分:
  - 维度: xxx
    材料证据: 材料中的依据
    用户原句: 用户的表述
    失分说明: 为什么失分
```

## 修改清单

```yaml
修改清单:
  - 序号: 1
    失分维度: xxx
    问题描述: 具体问题
    修改建议: 可操作的修改
    证据位置: 材料来源
```

## 使用说明

- 每次评分完成后由系统自动填充并写入 `<状态根>/作答记录/`
- 文件名格式：`<batch_id>-<seq>.md`
- 此记录是能力档案和学习者画像的数据源
- 不伪造评分数据——未评分的维度不写入
