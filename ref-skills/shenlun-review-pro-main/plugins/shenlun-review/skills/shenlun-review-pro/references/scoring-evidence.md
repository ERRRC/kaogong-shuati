# 申论批改依据层

本文件不是官方评分细则，而是根据课程阅卷经验、题型协议和真实批改样本整理出的运行规则。它独立于方法卡：方法卡负责“如何审题和操作”，本文件负责“哪些现象可以影响批改判断”。

## 一、小题基本边界

- 归纳概括、提出对策等低分值小题以材料点和关键词为主，允许有材料依据的同近义表达。
- 关键词不准确、主体/动作/对象发生实质替换时，不得仅因大意相近就判为完整覆盖。
- 一个总括词命中，不自动代表后续解释全部命中。
- 材料明确形成“总括词+必要解释”时，解释决定该点是完整覆盖还是部分覆盖；普通例子、效果和背景不自动升级为独立硬点。
- 材料口语化、没有稳定规范词时，可以按意思判断，但必须仍能回到材料事实或关系。

## 二、关键限定规则

只有会改变该做法/机制是否成立、如何落地或产生何种结果的内容，才可标为 `critical_qualifiers`。典型包括：

- 制度或机制的执行链条：方案编制、联动实施、闭环落实；
- 做法的主体、对象、范围、流程和关键动作；
- 对策的执行主体、工具、目标和必要保障。

缺少关键限定时，统一表述为“方向命中，但展开/落地链条不完整”，按部分覆盖或档内下沿处理。不能把每个例子、数据和效果都拆成关键限定。

## 三、材料逻辑与层次

- 合并要看主体、动作、段落位置和任务功能是否一致。
- 不得跨越材料逻辑，把原文不同阶段、不同主体或不同功能的信息强行合并。
- 原文存在局部总分关系时，答案总括词应能统领后文；只写后文细节但丢掉上位关系时，记录组织/层次风险。
- 轻微换序、合理概括和不影响阅卷识别的合并不自动扣分；只有破坏因果、递进、阶段或独立点识别时才影响档位。

## 四、证据等级

- `confirmed`：材料原句和题目任务均支持，可进入正式得分判断。
- `candidate`：有材料线索但存在粒度、归类或任务对应争议，只作提示。
- `disputed`：不同答案或材料关系存在未解决冲突，不得作为确定性漏点。
- OCR 未解决疑点不得作为唯一硬证据。

## 五、题型隔离

- 小题：点/关键词 + 必要解释 + 材料逻辑。
- 应用文：结构板块 + 内容要素 + 文种任务，不能套用小题或大作文模板规则。
- 大作文：立意、分论点关系、论证桥梁和材料支撑，不能把小题点数直接换算成作文分数。

## 六、分数分布的使用边界

- 国家层面的公开信息通常只有合格线、进面规则和职位最低分，不能当作全国申论原始分布。
- 机构文章和考生经验可提示“中段更密、高分稀少”，但样本可能只覆盖入围考生或宣传案例，证据等级低，不直接驱动单题分数。
- 单题校准采用部分覆盖 0.50 的保守中点；这只是把“方向命中但展开不全”和“完全未提及”拉开合理距离，不是官方逐点扣分表，也不用于强制正态化。
