# 申论方法库

本文件是申论方法库的统一索引。当前 84 张正式方法卡已完成工程化。

## 方法库状态

- 正式方法卡总数：**84 张**
- ID 范围：`sl-card-0001` 至 `sl-card-0084`，连续唯一
- 质量等级：A=70，B=14（仅 A/B 卡可发布）
- 方法层级：能力内核 5 张 / 题型工作流 55 张 / 批改二稿 24 张
- 任务原型：**26 个**（`task-prototypes/`）

**重要声明**：方法卡仅为辅助工具，不是评分标准。方法卡不能制造材料中不存在的得分点、不能修改评分权重或层级、不能把参考答案视为唯一答案、不能否定材料有据的等义表达。

## 路由边界

`SKILL.md` 是唯一运行流程来源。普通解析由 `analyze-once` 内部加载原型和方法卡，普通批改由 `grade-once` 内部完成；本索引不再定义底层 `resolve-*` 调用顺序。引擎返回的真实方法卡是本轮唯一可用的方法依据；没有真实回执时，禁止自创方法名。
- 每次每模式最多调用 **5 张** 方法卡
- 能力内核：默认 0–1 张
- 题型工作流：默认 1–3 张
- 批改二稿：必要时 0–1 张
- 不为凑数强行调用
- 得分点提取先于方法选择
- 方法选择不得反向修改 analysis-result 中的 atomic_points

面向用户时只把真正用到的方法融入讲解，默认不展示卡号、路由 JSON 或校验回执。用户要求查看方法依据时，再给出方法名和 card ID。

详见 `method-routing.json`。

## 质量等级规则

| 等级 | 条件 | 用途 |
|---|---|---|
| A | 来源可靠、方法可执行、触发条件明确 | 可直接用于讲解与评分 |
| B | 来源基本可靠、方法可执行 | 可用于讲解与评分 |
| C | 来源或执行性存疑 | 仅作检索线索，不得发布 |
| D | 来源不可靠或方法不可执行 | 必须跳过，不得发布 |

**发布限制**：只有 A/B 质量等级的方法卡可正式发布。C/D 候选不得进入正式卡目录。

## 方法库硬边界

1. 得分点只能来自材料和评分协议。
2. 方法库不能制造材料中不存在的得分点。
3. 方法库不能把参考答案视为唯一答案。
4. 方法库不能否定材料有据的等义表达。
5. 方法库不能修改评分维度、权重或算术。
6. 方法卡只辅助审题、找点、组织、表达、诊断和修改。
7. 发布卡不得包含老师名、平台名、来源文件名、本地路径、字幕时间戳或原话。
