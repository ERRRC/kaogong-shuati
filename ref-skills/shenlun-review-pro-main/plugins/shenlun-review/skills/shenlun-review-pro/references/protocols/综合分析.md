# 综合分析协议

本文件只定义该题型的证据、覆盖和定档细节。材料核验、作答映射和参考校准在同一次入口编译中完成；本文件不定义命令调用顺序。

## 题型识别信号

- "请分析……"
- "谈谈你的看法/理解/认识"
- "分析……的原因/影响/意义"
- "对此你怎么看"
- "综合分析"明确出现在题干或要求中
- 作答要求出现"观点明确、分析透彻、条理清晰"
- 题干要求分别解释多个概念，并说明它们之间的关系、联系、协同或作用机制

多概念题即使含“分别指什么”，只要还要求分析概念间关系，就不得降格为单纯归纳概括。解析时先分别定义每个概念，再提取输入、处理、验证、反馈或其他真实材料关系。

## 默认维度与权重

| 维度 | 权重 | 说明 |
|---|---|---|
| 任务符合 | 10 | 是否准确把握分析对象和角度 |
| 要点覆盖 | 30 | 是否全面覆盖分析涉及的核心要点 |
| 关系逻辑 | 30 | 各要点之间的逻辑关系是否清晰、因果/递进/并列是否准确 |
| 结论解释 | 15 | 结论是否有材料支撑、解释是否充分 |
| 组织表达 | 15 | 结构是否清晰、语言是否流畅 |

## 材料遍重点

- 提取所有与分析对象相关的事实、数据、观点
- 标注材料中的因果关系、对比关系、递进关系
- 区分事实信息和观点信息
- 标注分析对象的背景和限定条件

## 作答遍重点

- 检查是否涵盖了材料中的多角度信息
- 评估逻辑链条是否完整（原因→影响→结论）
- 检查结论是否有材料支撑
- 评估论证深度（是否停留在表面还是深入分析）

## 校准遍重点

- 参考答案的逻辑结构是参照，但允许不同的合理组织方式
- 等义逻辑关系（如因果与递进在特定语境下可互换）不扣分
- 结论的措辞可以不同，但核心判断方向需一致

## 常见失分模式

| 失分模式 | 典型表现 | 对应维度 |
|---|---|---|
| 角度偏差 | 分析方向偏离题目要求 | 任务符合 |
| 逻辑断裂 | 要点之间缺乏衔接，因果关系不清 | 关系逻辑 |
| 要点不全 | 只分析了部分角度，遗漏关键维度 | 要点覆盖 |
| 结论空泛 | 结论缺乏材料支撑，流于口号 | 结论解释 |
| 结构松散 | 段落之间缺乏逻辑递进 | 组织表达 |

## 修改建议方向

- 确认分析角度是否准确覆盖题目要求
- 补充遗漏的分析维度
- 强化要点之间的逻辑衔接
- 用材料事实支撑结论，避免空泛表态
- 调整结构，确保逻辑递进或并列清晰

## 字数门禁

综合分析题字数通常较紧（如 200 字）。审题必须记录 `min_length`/`max_length`/`length_unit`；解析参考答案正文实际字数必须落在区间内；批改和二稿必须计算用户正文实际字数，超限或不足必须诊断并影响对应维度（任务符合 / 组织表达）。字数统计口径与确定性校验见 `scoring-core.md` 字数门禁章节。

## 修改二稿方法卡路由

综合分析修改二稿**不设固定方法卡**（`method-routing.json` 中三类综合分析的"修改二稿"为空数组）。`sl-card-0057 对策篇幅控制` 为条件卡，仅当用户答案确实包含冗长对策且当前任务允许处理对策时，由调用方在 `validate-method-selection` 的 `conditional_reason` 显式声明"用户答案对策冗长"后方可调用；不得默认路由或为凑数调用。

## 覆盖映射中性示例

参见 `scoring-core.md` 护栏 10。用户明确写出核心语义（如"投诉有所增加"对应材料"投诉量同比增加 18%"）时，至少判"部分覆盖"或"等义表达"，不得判"未覆盖"；缺少数字限定时按"部分覆盖"处理。

## 维度等级锚点表

以下锚点使用跨题通用的可观察行为描述，不引用任何现有 E2E 材料。

### 任务符合（权重 10）

| 层级 | 锚点 |
|---|---|
| 0 | 未回应分析对象，或方向与题目要求相反 |
| 1 | 涉及分析对象，但大量内容偏离分析角度或混淆分析层次 |
| 2 | 基本围绕分析对象，但部分角度遗漏或层次不清 |
| 3 | 准确把握分析对象和角度，层次基本完整，仅有少量偏移 |
| 4 | 精准把握分析对象、角度和层次，全部内容紧扣题目 |

**注意**：不得把"没有额外建议"作为所有综合分析题的固定扣分项。仅当题目明确要求提出建议时，才可因未提建议扣任务符合；题目只要求"分析/谈看法/谈理解"时，无建议不扣分。

### 要点覆盖（权重 30）

| 层级 | 锚点 |
|---|---|
| 0 | 几乎未覆盖任何分析要点 |
| 1 | 覆盖少量要点，大面积遗漏关键事实或观点 |
| 2 | 覆盖部分要点，存在明显遗漏（如整类事实或关键观点缺失） |
| 3 | 覆盖大部分要点，仅有少量次要要点遗漏 |
| 4 | 全面覆盖所有核心要点，次要要点基本覆盖 |

### 关系逻辑（权重 30）

明确区分以下层次：

| 层级 | 锚点 | 行为特征 |
|---|---|---|
| 0 | 无逻辑或逻辑完全错误 | 要点堆砌无关系，或因果关系颠倒 |
| 1 | 仅罗列材料信息 | 有要点但未建立任何关系，因果/对比/递进均缺失 |
| 2 | 建立局部关系 | 部分要点之间有因果或对比关系，但主要逻辑链断裂或不完整 |
| 3 | 建立主要逻辑链 | 核心要点之间形成完整因果/对比/递进链条，仅有局部关系不够清晰 |
| 4 | 完整解释对象、关系和结论 | 全部要点形成完整逻辑网络，因果/对比/递进层次清晰，结论由逻辑推导得出 |

### 结论解释（权重 15）

只评价题干所问对象的结论及其材料支撑。题干未要求背景、意义或政策定位时，缺少这些内容不得降低“结论解释”档位。普通的内容漏点归“要点覆盖”，不在本维度重复扣分。

| 层级 | 锚点 |
|---|---|
| 0 | 无结论或结论与材料矛盾 |
| 1 | 有结论但缺乏材料支撑，流于口号或主观表态 |
| 2 | 有结论且有部分材料支撑，但解释不充分或结论偏弱 |
| 3 | 结论有材料支撑，解释基本充分，仅有局部论证不够深入 |
| 4 | 结论准确、有充分材料支撑，解释深入完整，能有效回应对象的核心问题 |

### 组织表达（权重 15）

本维度只看层次、衔接、语句可读性和表达精确度。在未违反题面最低字数时，不得因答案没有“尽量写满”字数上限而降档；内容遗漏也不得在本维度重复扣分。

| 层级 | 锚点 |
|---|---|
| 0 | 结构完全混乱，语言不可读 |
| 1 | 有初步结构但层次混乱，语言问题严重 |
| 2 | 结构基本清晰，但段落衔接不够流畅或语言存在明显问题 |
| 3 | 结构清晰，语言流畅，仅有少量表达可优化 |
| 4 | 结构严谨，逻辑递进清晰，语言精炼准确 |

## 逐点计分模式（v0.4）

内部点值只用于同一点池的稳定复算，不是官方单点分值或固定扣分表。

综合分析题使用 **semantic（按意思/等义）** 赋分模式。

### 点值分配规则

1. 点池应围绕题干要求的解释、关系、原因、影响或结论功能建立，不把每句论据机械拆成独立硬点。
2. 观点、论据与结论可作为一个主点的内部链条；只有承担独立任务功能时才分拆。
3. 材料口语化严重时按意思给分，等义表达不因用词和句式不同单独降分。

### 关键词匹配规则

- 用户答案表达出材料中的意思 → 满分（证据 2-4：多种写法均可得分）
- 不要求精确关键词，只要核心语义一致
- 前后变化类题：不必出现精确对比词，只要出现变化的意思即可（证据 2-5）

### 展开度

综合分析使用展开度判定：
- 观点+充分论证+材料支撑 → 充分展开
- 有观点但论证不充分 → 简略提及
- 只列观点无展开 → 仅列标题
