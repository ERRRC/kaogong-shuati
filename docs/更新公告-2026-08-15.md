# 📢 更新公告

**版本：v1.12 ｜ 日期：2026-08-15**

本次更新带来「自定义题库」重磅功能，并同步优化了 AI 解析、科目分类与刷题体验。以下是完整更新内容。

---

## ✨ 一、重磅新功能：自定义题库

以后再也不用羡慕别人的题库了——**你自己的题，也能刷！**

- **多种导入方式**：支持上传 **PDF、Excel、Word、TXT** 文件，也支持**图片导入**（拍照/截图自动识别题目）和**直接粘贴文字**，怎么方便怎么来
- **智能解析引擎**：导入后自动把题目拆分成 **题干 / 材料 / 选项 / 答案 / 解析** 五大要素，无需手动整理
- **智能细节处理**：
  - 一行里的多个选项自动拆分（如「A. 甲 B. 乙 C. 丙」自动分成三个选项）
  - 判断题选项自动补全（「正确 / 错误」）
  - 重复题目自动去重，封面页、页眉页脚自动过滤
- **批次管理**：一次导入的文件就是一个「批次」= 一个独立题库分支，支持**改名、合并、拆分、删除**，想怎么整理都行
- **单题编辑**：任何一道题都可以单独修改、删除，导入错了也能当场改
- **完整刷题闭环**：自定义题和真题一样能**刷题、判分、进错题本、收藏、单题重做**

## 🗂 二、科目分类（导入时自选）

- 导入新题目时可以选择科目：**行测 / 职测 / 综应 / 申论**
- 题库列表显示科目标签，一眼看清这批题属于哪个科目
- 刷题记录、错题本、统计都按科目归属，自定义题也不游离在体系外

## 🤖 三、AI 能力全面升级

- **自定义题支持 AI 解析**：刷自定义题点击「AI 解析」，AI 会给出【考点】【正确项解析】【错误项排除】【解题技巧】，和真题解析一个待遇
- **材料题、多选题、无答案题**全部兼容，材料自动带入分析
- **导入兜底解析**：规则识别不出的题目格式，自动交给「题目解析员」AI 结构化整理，减少导入失败
- **AI 网关优化**：配置一次 API Key 即可使用，App 端解析不再频繁限流

## 🛠 四、修复与优化

- ✅ 修复无答案题被误判为答错的问题
- ✅ 修复自定义题进不了错题本/收藏的问题
- ✅ 修复拆分批次丢失科目归属的问题
- ✅ 修复 PDF 导入换行丢失、选项错乱的问题
- ✅ 修复图片导入、Excel 导入偶发失败的问题
- ✅ AI 未配置 Key 时给出明确提示，不再只显示「解析失败」
- ✅ 优化 AI 设置页界面（移除使用统计展示，避免误解）
