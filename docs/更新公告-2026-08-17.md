# 更新公告 v1.13 → v1.24

事情是这样的，上次写更新公告还是 V1.13，也就两天前，结果这两天一口气更新了十来个版本，攒了不少东西，今天一次讲完。

这次重点说三件事，自定义刷题、技能库、网关切换。

先说自定义刷题。之前做了自定义题库，可以把 PDF、Excel、图片里的题导进来自己攒题库，但题导进来了，怎么刷？之前只能一整套一整套过。现在好了，从你导入的批次里直接抽题刷，真题和自定义题一个待遇，判分、进错题本、收藏全都有。还顺带做了背题模式，先给你看答案再让你作答，适合常识、时政这种需要硬记的知识点，过一遍特别快。

然后是这次最大的一块，技能库。以前 AI 设置页那几个智能体，能力是死的，只能按写死的提示词干活，想换思路得自己改大段提示词。现在搞了个技能库，你可以把技能包导进去，SKILL.md 文件、zip 压缩包、粘贴文本、在线链接都行，App 自动识别内容。更好玩的是，你直接粘贴「安装 xxx 技能」这种话，App 会自己去技能商店把技能拉下来装好。内置的公考华师技能和申论技能也做了一键导入，行测 AI 和申论 AI 的 Skill 字段直接下拉选择，选哪个用哪个，以前折腾一圈的事现在点两下就完事。

网关这块也顺手改了。之前行测和申论 AI 的网关地址要手动填，换网关就得复制粘贴一长串网址，还得核对 API Key，填错了就 401、403 报错，挺闹心的。现在常用网关做成下拉，opencode、商汤、智谱点一下切换，换完还能一键拉模型列表直接选模型，切换时 App 会提醒你核对 Key，免得换网关忘了换钥匙。

顺带把题库精简也讲了。以前刷题偶尔会碰到题面发黄的老卷子，考点全是十几年前的套路。现在全题库只保留近十年真题，2017 到 2026，年份还会自动往前滚，随机练习、专项练习、智能组卷都只抽新题。错题本和收藏里的老题不受影响。

剩下的是一堆零零碎碎的修复。浏览器端「获取模型列表」跨域被拦的问题修了，技能导入的各种边界情况修了，App 端章节统计补上了近十年过滤，技能库列表改成纯标题更清爽了。题数口径也统一了，以前行测章节页显示五万多实际只有两万四，同一道题跨卷重复计数没去重，数字就翻倍了？？？现在显示多少就能刷多少。

以上就是这两天的全部更新，一次讲完了。用着有什么问题，或者想要什么新功能，随时跟我说。

**感谢使用！** 有任何问题或建议，欢迎随时反馈，我们会持续优化。
